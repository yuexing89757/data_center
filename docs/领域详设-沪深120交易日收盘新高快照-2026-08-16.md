# 领域详设：沪深 120 交易日收盘新高快照

## 边界与口径

该领域是 `core.daily_bar` 的确定性客观派生，不表达交易建议。候选只包含交易日当时生命周期有效的
SSE/SZSE `stock`；BSE 和其他证券类型不进入候选。窗口由 `CN_A_SHARE` 日历截至目标日期的精确
120 个交易日构成。每只证券必须有 120 条正收盘记录，状态只允许 `trading` 或 pytdx 的
`unknown`。当日收盘严格大于此前 119 日最高收盘才成为成员，相等不算。

价格为 `numeric(18,4)`/Decimal；`breakout_pct=(close/previous_119d_high-1)*100`，保存为
`numeric(24,10)`。成员按突破百分比降序、symbol 升序稳定排列。缺历史、明确非交易、非正价格和
缺目标日历史名称均保留为分组遗漏计数；同一候选可命中多个分组，唯一遗漏数不重复计算。

## 输入、计算与版本

Persistence 先检查精确目标日是交易日、已有同日 `daily_market` 的 succeeded/partial 终态，并取得
120 日首末边界。日 K 通过 `(market,trade_date)` 范围索引有界读取，数据库只产生每证券聚合输入；
纯 Calculator 完成资格、Decimal 比率、排序和哈希。

输入哈希覆盖算法版本、窗口及排序后的候选聚合输入，内容哈希覆盖排序后的成员。相同 trade date 和
input hash 幂等复用；修订输入创建新的 calculation 和递增 snapshot version。Calculation、snapshot
和 members 在一次发布事务中完成，失败不产生半快照。成功零成员仍发布 ready 主记录。

## 表与权限

- `derived.close_price_new_high_120d_snapshot`：不可变版本主表和质量计数。
- `derived.close_price_new_high_120d_member`：快照成员及计算时名称/价格。
- Worker 角色通过 RLS 获得所需 select/insert；API 角色没有底表权限。
- `api_v1.query_close_price_new_highs_120d()` 是唯一公开读契约，只读最近日期最高版本 ready 快照。

## Worker 任务

代码目录任务 `close-price-new-highs-120d-daily` 固定周一至周五 21:30 Asia/Shanghai，默认启用；
`CLOSE_PRICE_NEW_HIGHS_120D_ENABLED` 只控制启停，不配置执行时间。任务属于
`close_price_new_highs_120d` workflow，唯一 step 为
`build_close_price_new_highs_120d_snapshot`。非交易日或依赖不完整时不发布快照，Operations 保留
终态；受控手工命令要求显式日期：

```bash
uv run market-data-center close-price-new-highs-120d-build --trade-date 2026-08-14
```

## API 新鲜度

`GET /api/v1/close-price-new-highs-120d` 无参数、不分页。21:30 新快照发布前、休市日或新任务失败时，
返回最近 ready 快照并通过 `trade_date` 明示日期；没有任何 ready 快照时返回 not found。FastAPI
请求不触发计算、采集或网络访问，也不读取 `core.daily_bar`。

# 沪深全市场竞价序列买一价量额领域详设

## 时间与字段规则

唯一边界是 Round 的 `scheduled_at`，转换至 `Asia/Shanghai` 后应用：

```text
scheduled_at < 09:25:00
last_price = bid1.price
cumulative_volume = bid1.volume
cumulative_amount = bid1.price * bid1.volume
value_semantics = auction_indicative
```

买一量已在 Provider 边界从手转换为股。买一价或买一量任一缺失时，三个目标字段同为 NULL。
不要求买一等于卖一，不从卖一、昨收或其他档位回退。最高价和最低价不由买一推导。

`scheduled_at >= 09:25:00` 时，价量额继续使用 pytdx 的普通成交字段，并标记
`opening_trade`。迁移前已有记录只标记 `legacy_source_quote`，不回写历史值。

## 组件职责

- `providers/pytdx_hq.py`：规范化原始五档、Decimal 和手到股的单位，不选择任务语义；
- `call_auction_market_series_service.py`：在 `_series_values` 中按计划时间选择买一值或成交值；
- `domain/call_auction_market_series.py`：验证语义枚举、边界、三字段同空/齐全及金额乘积；
- `persistence/call_auction_market_series_postgres.py`：显式写入已计算字段和语义，不重新计算；
- ordered migration：标记历史、建立约束并替换 bounded RPC；
- FastAPI：原样暴露 `value_semantics`，不访问内部表或触发采集。

## 不变量与质量

`auction_indicative` 的价、量、额必须三者齐全或三者同空。齐全时金额必须精确等于 Decimal
价格乘整数股数。所有非空值非负，`last_price` 仅在来源高低价非空时继续接受原范围校验。
Raw schema 和来源 Raw 行保持不变，便于重放能力被后续 ADR 接受后验证标准化结果。

## 读取与历史

`api_v1.query_call_auction_market_series_snapshots(date,text[])` 的每个 item 增加必填
`value_semantics`。既有参数、session 选择、轮次顺序、缺失代码、5 秒 timeout 和 API 角色权限不变。
本变更不对 2026-08-17 或更早快照执行数据回填。

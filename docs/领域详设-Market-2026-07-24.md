# 领域详设：Market Daily Bar v2

> 状态：第一阶段有效  
> 修订日期：2026-07-27  
> 依据：`adr/ADR-0001-第一阶段架构基线.md`

## 1. 领域职责

Market 第一阶段只维护证券日频、不复权的量价事实。复权价格、移动平均、收益率、估值、市值、涨跌停和市场统计均不在第一阶段范围内。

Market 依赖：

- Security：确认 `symbol`；
- Trading Calendar：确认 `trade_date` 是 `CN_A_SHARE` 交易日；
- Ingestion：追溯来源和 Raw 对象。

## 2. 实体：DailyBar

数据库表：`core.daily_bar`

| 字段 | 类型 | 单位与含义 |
| --- | --- | --- |
| `symbol` | text | 统一证券标识，联合主键 |
| `trade_date` | date | Asia/Shanghai 交易日，联合主键 |
| `market` | text | 第一阶段固定 `CN_A_SHARE` |
| `open` | numeric(18,4) | 人民币元，不复权 |
| `high` | numeric(18,4) | 人民币元，不复权 |
| `low` | numeric(18,4) | 人民币元，不复权 |
| `close` | numeric(18,4) | 人民币元，不复权 |
| `previous_close` | numeric(18,4) | 前一有效交易日不复权收盘价，可空 |
| `volume` | bigint | 股 |
| `amount` | numeric(24,2) | 人民币元 |
| `trade_status` | text | `trading`、`suspended`、`unknown` |
| `is_st` | boolean | 当日 ST 状态，可空 |
| `source_code` | text | 标准来源标识，第一阶段为 `baostock` |
| `ingestion_id` | uuid | 采集批次 |
| `created_at` | timestamptz | 创建时间 |
| `updated_at` | timestamptz | 最近更新时间 |

主键：`(symbol, trade_date)`。

外键：`(market, trade_date)` 关联 `core.trading_calendar(market, trade_date)`。价格和金额必须使用上述定点精度，Python 中使用 `Decimal`，不得先转换为 float。

## 3. 事实口径

- 只保存不复权价格；
- 来源若默认返回复权数据，Provider 必须显式请求不复权；
- 不用前复权序列覆盖历史事实；
- `volume` 统一为股，Provider 负责手、股等单位转换；
- `amount` 统一为人民币元；
- 涨跌幅不作为第一阶段权威字段，可由价格按版本化规则派生；
- 停牌是证券×交易日状态，属于 Market，不写入 Security。

## 4. 停牌记录

如果来源能够明确给出停牌事实，应保存该交易日记录：

- `trade_status='suspended'`；
- OHLCV 是否为空按来源事实映射，不伪造为零；
- 零成交量与缺失成交量语义不同；
- 来源无法判断时使用 `unknown` 并产生质量提示。

## 5. 标准 DTO

```text
DailyBarRecord
├── symbol
├── trade_date
├── market
├── open / high / low / close
├── previous_close
├── volume
├── amount
├── trade_status
├── is_st
└── source_code
```

DTO 不包含 `adjustflag`、`pctChg`、`isST` 等来源专用字段，也不包含 `ingestion_id`。Pipeline 使用 `IngestionEnvelope[DailyBarRecord]` 附加批次 ID。

## 6. 幂等与修订

- 按 `(symbol, trade_date)` upsert；
- 同一采集批次重复执行结果一致；
- 数据源后续修订同一日行情时允许更新事实，但必须保留最新 `ingestion_id`；
- Raw 对象不可覆盖，确保修订前后均可追溯；
- 若需要完整修订历史，后续通过新 ADR 引入事实版本表。

## 7. 校验

严重失败、禁止入库：

- `symbol` 不存在于 Security；
- `trade_date` 不是已知交易日；
- `low > high`；
- OHLC 超出 `[low, high]`；
- 价格、成交量或成交额为负；
- 同批次自然键重复且内容冲突。

质量告警、允许按策略入库：

- `previous_close` 缺失；
- `trade_status` 未知；
- 停牌记录仍有非零成交量；
- 与上一交易日存在异常跳变。

## 8. API 契约

`api_v1.daily_bars` 只读 View 公开：

```text
symbol, trade_date,
open, high, low, close, previous_close,
volume, amount, trade_status, is_st
```

API 必须支持按 `symbol` 和日期范围过滤。内部 `source`、`ingestion_id` 和审计时间默认不公开。

## 9. 第一阶段验收

- BaoStock 明确请求并返回不复权日线；
- 单位转换由 Provider 契约测试覆盖；
- 重复同步保持幂等；
- 非交易日行情不能进入 Core；
- 异常 OHLC 被阻止并形成质量结果；
- PostgREST 可按证券和日期范围查询；
- 任一行情记录可追溯到采集批次和 Raw 文件。

# 开盘啦市场情绪历史股票列表实时接口

本接口按指定历史交易日，请求时读取开盘啦 App「行情 → 打板 → 历史数据 → 股票列表」；它不是盘中实时行情。数据不入 PostgreSQL 或 Raw，不触发 Worker，也不修改现有 `/api/v1/realtime/kaipanla/auction-pool`。

四个独立 GET 路由：

|列表|路径|来源 `PidType/Type/Order`|2026-09-28 页面数量|
|---|---|---|---:|
|竞价|`/api/v1/realtime/kaipanla/market-emotion/stocks/auction`|`8/18/1`|143|
|涨停|`/api/v1/realtime/kaipanla/market-emotion/stocks/limit-up`|`1/6/1`|33|
|跌停|`/api/v1/realtime/kaipanla/market-emotion/stocks/limit-down`|`3/6/1`|56|
|炸板|`/api/v1/realtime/kaipanla/market-emotion/stocks/broken-limit-up`|`2/4/1`|11|

所有路由要求 `X-API-Key` 和 `trade_date=YYYY-MM-DD`；日期必须早于当前上海日期。`offset` 默认 0、范围 0–10000；`limit` 默认 30、范围 1–30。每次仅请求上游一页，不重试、不自动翻页、不回退日期。来源未给可靠总数，`total` 固定 `null`；满页的 `next_offset` 仅表示可尝试下一页，不保证跨页快照一致。固定过滤 ST，调用方不能改上游 action、类别、排序或 URL。

统一外层字段：`source_code="kaipanla"`、`list_type`、`persisted=false`、`requested_date`、`trade_date`、`observed_at`、`offset`、`limit`、`returned_count`、`total`、`next_offset`、`items`。`observed_at` 为取回响应的上海时间，不是股票事件时间，例如 `2026-09-29 01:00:00`。日期为 `YYYY-MM-DD`；时间为 `YYYY-MM-DD HH:mm:ss`；缺失为 `null`，零保持零，Decimal 金额与百分比序列化为字符串。

每条均有六位 `code`、标准 `symbol`、`name`；类别字段如下：

|类别|额外字段|单位与来源语义|
|---|---|---|
|竞价|`board_name`、`limit_up_bid_amount_cny`、`auction_change_pct`、`change_pct`、`auction_net_amount_cny`、`auction_amount_cny`、`auction_turnover_rate_pct`、`actual_float_market_value_cny`|板块文字；委买额/净额/成交额/实际流通市值为元；两种涨幅及换手率为百分比|
|涨停|`limit_up_at`、`status`、`reason`|涨停时间、来源首板/连板状态、来源涨停原因|
|跌停|`limit_down_at`、`sealed_amount_cny`、`board_name`|跌停时间、来源封单金额（元）、来源板块文字|
|炸板|`change_pct`、`limit_up_at`、`opened_at`|涨跌幅（百分比）、涨停时间、开板时间|

来源固定为 `https://apphis.kaipanla.com/w1/api/index.php` 的 `HisHomeDingPan/HisDaBanList` 历史 POST，`Day` 精确匹配请求日期；`Index`/`st` 对应分页，其他过滤及版本参数沿用已验证的竞价接口。2026-09-28 的页面数量和类别参数经 App 页面及限定历史查询交叉核对；同一分钟股票的来源秒级排序可能与 App 分钟级显示顺序不同。只公开已确认语义的字段，不返回来源行尾部或 `source_values`。

无密钥返回 401；非法/当日/未来日期或分页参数返回 422；来源超时、失败、HTML 占位、日期不符或不可信字段返回 502。只有来源明确成功、日期匹配且列表为空，才返回 200 空 `items`。响应不保存来源正文，不含登录凭据。App 当日 Socket 2103 不在本接口范围内。

`change_pct` 是所查询历史日期的来源行情涨幅，不是查询此刻的实时涨幅。
来源没有返回这些指标的精确事件时点，`observed_at` 只是响应接收时间。
来源“竞价成交额”不等于已经独立验证09:25最终撮合金额；使用前需补足时点证据。
来源实际流通是市值（元），不是股数，不能保证按上一交易日收盘价计值。
换手率为百分数，例如0.23表示0.23%，不要再次乘100。

当日全天成交额不与竞价成交额混用。本列表没有已核实的全天成交额映射；
本次不猜测数组下标、不伪造字段或零值。消费者应另取确切交易日的
`api_v1.query_daily_bars`的`amount`（CNY，未复权日线）或已核实的MySQL日成交额字段，
明确收盘后的日成交时点并保留缺失。

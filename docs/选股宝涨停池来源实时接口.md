# 选股宝涨停池来源实时接口

任务：[#101](https://github.com/yuexing89757/data_center/issues/101)。治理依据：
[ADR-0067来源增补](adr/ADR-0067-竞价九合一来源实时只读接口.md)。
本接口提供来源最新可用观察，不替代数据中心经认证的涨跌停事实或日终股票池。
2026-10-28已部署API版本`9fe6462`，详见[发布验收](runbooks/xuangubao-limit-up-release-2026-10-28.md)。

## 调用与来源

`GET /api/v1/realtime/xuangubao/limit-up`，请求头`X-API-Key: <既有API密钥>`，无查询参数。
Swagger归入“实时接口”。上游固定匿名GET：
`https://flash-api.xuangubao.cn/api/pool/detail?pool_name=limit_up`。
请求头为`User-Agent: Mozilla/5.0`、`Referer: https://finance.sina.com.cn/`、
`Accept: application/json`，不需要来源Cookie或Token。要求来源整数`code=20000`且`data`为数组。
一次请求只读取一次完整来源池，不自动重试、翻页、缓存、筛选ST或重新排序。

仅接入此最新池，不接受日期来查询历史，也不补充同花顺、其他池或独立题材接口。
不计算成交额、封单金额或策略结论。无数据库、Raw、Worker或PostgREST变更。

## 时间与响应元数据

响应固定`source_code=xuangubao`、`source_name=选股宝`、`source_layout=xuangubao.limit_up.v1`、
`persisted=false`，带固定`source_url`、`returned_count`及来源顺序的`items`。
`observed_at`是实际收完响应的上海时间，不是来源更新时间。
`source_date`仅由每条股票的当前`first_limit_up`/`last_limit_up`事件核对：

- 全部记录至少有一个有效事件日期且全池一致：返回该日期，`date_status=verified_from_events`。
- 空池或任一记录缺乏当前事件证据：日期为`null`，`date_status=unknown`。
- 出现未来时间、同一记录首末时间倒序或混合来源日期：整批502。

这不是交易日历认证或实时新鲜度承诺；闭市、跨日后返回上一来源日属于来源最新池语义。
所有时间戳使用共享`ApiTimestamp`，转换为上海`YYYY-MM-DD HH:mm:ss`，不带小数和时区尾缀；
Unix秒0或缺失表示无事件、返回`null`。日期字段为`YYYY-MM-DD`。

## 字段映射

数值JSON用`Decimal`解析，价格/比例及未核实来源数值在API中序列化为十进制字符串；
不经过`float`。真实零为`"0"`，缺失为`null`；计数是JSON整数。非有限数值拒绝。

| 来源字段 | 公共字段 | 解释 |
|---|---|---|
| symbol | symbol、source_symbol | 如000678.SZ→SZSE:000678；.SS→SSE，.BJ→BSE；校验交易所前缀 |
| stock_chi_name | name | 来源名称 |
| price、issue_price | last_price、issue_price | 人民币元；非负 |
| change_percent、turnover_ratio | change_ratio、turnover_ratio | 小数比例，0.1=10%；不乘100，换手非负 |
| listed_date | listing_date | 来源Unix秒对应的上海日期 |
| first_limit_up、last_limit_up | first_limit_up_at、last_limit_up_at | 当前首次/最后涨停时间 |
| first_break_limit_up、last_break_limit_up | first_break_limit_up_at、last_break_limit_up_at | 当前首次/最后开板时间 |
| first_limit_down、last_limit_down | first_limit_down_at、last_limit_down_at | 当前首次/最后跌停时间 |
| first_break_limit_down、last_break_limit_down | first_break_limit_down_at、last_break_limit_down_at | 当前首次/最后打开跌停时间 |
| yesterday_first_limit_up、yesterday_last_limit_up | yesterday_first_limit_up_at、yesterday_last_limit_up_at | 来源昨日涨停时间，不用于推定当前池日期 |
| limit_timeline.items | timeline | timestamp→at，status→source_status；保留顺序及未知状态码 |
| surge_reason | source_reason | symbol→标准代码，stock_reason→text，related_plates保留池内板块文字 |

`source_reason.related_plates`的`plate_id/plate_name/plate_reason`分别映射为
`source_id/name/reason`；ID属于选股宝，非数据中心分类ID。原因原文是来源观点，
不认证为事实、不生成交易判断。时间线已观察到状态1封板、2开板，未声称完整枚举。

`source_counts`包括来源计数，非中心重算结果：

| 来源字段 | 公共字段 |
|---|---|
| limit_up_days、limit_down_days | limit_up_days、limit_down_days |
| yesterday_limit_up_days、yesterday_limit_down_days | yesterday_limit_up_days、yesterday_limit_down_days |
| break_limit_up_times、break_limit_down_times | break_limit_up_count、break_limit_down_count |
| yesterday_break_limit_up_times | yesterday_break_limit_up_count |
| m_days_n_boards_days、m_days_n_boards_boards | multi_board_days、multi_board_count |

下列字段放在`source_statistics`中，仅转述未核实数值，**不作为标准数量、金额或派生计算输入**。
不因为字段名称猜测股/手/人民币单位，也不宣称`stock-quantity.v1`认证：

| 来源字段 | 公共字段 | 尚未核实 |
|---|---|---|
| buy_lock_volume_ratio、sell_lock_volume_ratio | buy_lock_ratio、sell_lock_ratio | 分母及单位 |
| stock_type | stock_type_code | 枚举 |
| is_new_stock、new_stock_break_limit_up | new_stock_flag、new_stock_break_flag | 来源标记口径；布尔值转0/1 |
| mtm、volume_bias_ratio | momentum_value、volume_bias_ratio | 计算口径 |
| total_capital、non_restricted_capital | total_capital_value、non_restricted_capital_value | 单位，不能当股本或人民币市值 |
| nearly_new_acc_pcp、nearly_new_break_days | nearly_new_accumulated_change、nearly_new_break_days | 统计口径 |
| new_stock_acc_pcp、new_stock_limit_up_days | new_stock_accumulated_change、new_stock_limit_up_days | 统计口径 |
| new_stock_limit_up_price_before_broken | new_stock_pre_break_price | 统计口径 |

仅映射以上42个已观察的来源字段，未知新增键不自动公开；不存在全量原始对象透传。
完整schema见[FastAPI契约](../contracts/fastapi-openapi-v1.json)。

## 边界、错误及配置

`FASTAPI_XUANGUBAO_TIMEOUT_SECONDS`默认8，可设1～10秒。受限DNS、单地址连接、
TLS校验、请求及读取共享网络截止时间；关闭系统代理和重定向，不进行端点发现。
正文上限2,000,000字节，池最多5,000项，每只股票时间线最多2,000项、板块最多100项。
重用现有受限连接器，不新增后台采集任务。

| HTTP | 含义 |
|---|---|
| 200 | 来源明确成功，包括真实空数组 |
| 401 | 原有API Key鉴权失败，不访问上游 |
| 502 upstream_error | HTTP/网络/来源失败、超限、结构异常、代码不符、重复证券或JSON键、非法数值或日期；不泄露上游异常文本 |

失败不截取部分成功列表，不补零、不跨源兜底。无分页不等于宣称全市场完整。
测试使用人工构造响应，不提交线上Raw或凭据。2026-10-28 00:23:57上海时间的一次
只读抽查返回42条、事件日期2026-10-27；这是跨日语义的实测例证，不构成长期可用性保证。
生产发布需另行明确授权。

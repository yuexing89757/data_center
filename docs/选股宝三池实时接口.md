# 选股宝三池实时接口

对应 [Issue #102](https://github.com/yuexing89757/data_center/issues/102) 和
[ADR-0075](adr/ADR-0075-选股宝三池只读接口.md)。本地实现，尚未部署生产。

## 观潮来源核对

观潮 `marketdesk/marketdesk/echelon_data.py` 的 `_daily` 读取
`https://flash-api.xuangubao.cn/api/pool/detail`，上游参数：

| 数据 | pool_name | 观潮使用的来源字段 |
|---|---|---|
| 涨停 | limit_up | limit_up_days：连续板数；change_percent：当天涨跌比例 |
| 炸板 | limit_up_broken | yesterday_limit_up_days：前日连续板数；change_percent：当天涨跌比例 |
| 昨日涨停股当天表现 | yesterday_limit_up | yesterday_limit_up_days；change_percent |

观潮涨停档位直接用 limit_up_days；炸板/昨日涨停档位为 yesterday_limit_up_days + 1。
涨停→炸板→昨日涨停按证券去重，最后剩余昨日池为界面断板侧。数据中心保留原始事实，
不替消费者计算档位、不把昨日池直接称为断板池、不混合开盘啦名单。

## 公共契约

`GET /api/v1/realtime/xuangubao/stock-pools`

- 必填 `pool_type`：`limit_up` / `broken_limit_up` / `previous_limit_up`。
- 可选 `trade_date=YYYY-MM-DD`：不得未来。历史向来源传 `date`；当天或省略不传来源日期。
- 直接访问数据中心带 `X-API-Key`；经 JeecgBoot 前缀 `/emo/data/proxy` 时带 `X-Access-Token`，
  API Key 由 JeecgBoot 服务端配置注入。
- 每次完整读取来源返回的一份池列表，无本地分页，最大2000条/2,000,000字节；不进行本地 ST 过滤。
- 单次请求复用 FASTAPI_XUANGUBAO_TIMEOUT_SECONDS 总网络截止时间（默认8秒，范围1–10秒），无自动重试、日期回退、跨源补全、重定向或系统代理。

示例路径（部署后使用）：

```text
/emo/data/proxy/api/v1/realtime/xuangubao/stock-pools?pool_type=limit_up
/emo/data/proxy/api/v1/realtime/xuangubao/stock-pools?pool_type=broken_limit_up&trade_date=2026-10-28
/emo/data/proxy/api/v1/realtime/xuangubao/stock-pools?pool_type=previous_limit_up&trade_date=2026-10-28
```

字段：标准 `symbol`（SSE/SZSE/BSE）、六位 `code`、`name`、`change_pct`、
`consecutive_limit_up_days`、`previous_consecutive_limit_up_days`、`topics`，以及
`first_limit_up_at`、`last_limit_up_at`、`last_broken_limit_up_at`、`previous_last_limit_up_at`。
change_pct 通过 Decimal 将来源比例乘100，序列化为字符串；不能再乘100。
板数0保持0，缺失和来源-1哨兵为null；不从“几天几板”推测连续板数。
事件时间0/缺失为null，其余为上海时间 `YYYY-MM-DD HH:mm:ss`。

## 日期与失败语义

- `requested_date`：调用方传入的日期，省略为null。
- `source_event_date`：本期首次/末次涨停及末次开板事件的一致日期；不使用昨日时间。
- `date_verification=event_dates_consistent`：只表示返回记录里出现的本期事件日期一致，
  并与显式请求日期一致。不能独立验证昨日池所有未触板股票的涨幅时间。
- 没有本期事件，包括真实空列表：`source_event_date=null`、`date_verification=unverified`。
- 最新请求允许显式返回旧事件日期；不得把观测日期当作今天行情。历史错日/混日为502。
- `observed_at` 是请求完成后的观测时间；`persisted=false`；无数据库和Raw落地。
- 无效或缺失API Key为401，参数无效422，上游失败、结构错误、重复代码、超限、日期冲突502。
  成功空列表200；空池不能自动证明当天休市。

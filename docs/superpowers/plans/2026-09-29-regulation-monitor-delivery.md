### 数据中心任务需求清单

1. **事实准备与覆盖盘点**：复用证券主数据、交易日历、股票日线、三个正确基准指数、换手指标、公司行为及适用性事实；输出缺失日期、证券、原因和数据水位。不得将缺失填零。
2. **规则与适用性判断**：按已确认的主板/创业板规则逐条计算；返回规则代码、中文名、级别、方向、窗口、基准、当前值、门槛和不适用原因。
3. **连续收盘事件生产**：按交易日顺序生成独立测算事件、模拟重置状态、批次与检查点；同日同方向同类型去重，支持幂等和更正后的连续重算；不写正式公告事件表。
4. **近10交易日次数**：上涨、下跌、换手独立统计，提供事件日期与命中规则、计数截止日；严重次数规则另给重置后的有效同向次数。盘中暂态不累计成历史事件。
5. **当日动态条件**：使用已发布基础和有效实时股票/指数行情，输出触发价格、所需涨跌幅、可达性、观察时点；行情过期或依赖不足必须明确标识。
6. **下一交易日动态条件**：用当前价假设收盘，按指数-2/0/+2%情景计算实际下一交易日门槛；返回假设时点和重置分支。参考价未知不输出价格，换手规则不反解价格。
7. **稳定对外接口**：提供固定批次候选列表和当前页批量监控查询；保持鉴权、有界分页/批量、Decimal字符串、上海时间、null语义与明确错误；公开接口不触发补采/补算。
8. **任务与运维能力**：默认只读预检；经单独授权后必要补数与连续补算；复用既有日终Worker步骤持续更新，提供成功/部分失败、覆盖和最新批次记录。
9. **接口交付包**：交付实际接口文档、请求/响应样例、字段单位、统计口径、错误与缺失状态、代表股票核验记录及数据覆盖报告；全部基于真实发布批次，不以模拟响应代替。

当前阶段完成标准：不用启动Java或页面，也能直接调用data_center接口，核对真实股票的规则、今日/次日条件和近10日次数；缺失项可定位，结果有来源和批次，持续更新能力有独立验收记录。达到该标准后再进入消费者阶段。

已批准规则：主板3日价格偏离 ±20%，创业板 ±30%；主板3日日均换手/前5日日均达到30倍且3日累计达到20%；10日同向价格异动主板4次、创业板3次；10日累计偏离 +100%/-50%；30日 +200%/-70%。累计偏离沿用已接受的区间复合收益差口径，不在消费者端另写一套算法。

## 二、当前问题的分层判断

1. **旧来源缺字段**：旧开盘啦聚合不能稳定提供四个目标栏位；不能靠前端默认值解决。
2. **发布与数据基础缺失**：前次成功只读探测确认新表/RPC 不存在；随后一次连接失败，因此执行前必须重查，不能假定环境未变。
3. **服务版本/地址没有联动切换**：已有本地服务运行不代表已加载新代码，也不代表 Java 正在调用本地 data_center。
4. **历史事实可能不足**：连续状态从规则有效起点或可信检查点开始；历史换手指标保留期可能造成缺口，不能只取最近30天重新把次数从零算起。
5. **预检诊断粒度不足**：现有 `preflight()` 提供日期、数量和状态原因汇总；未完整给出逐股票/规则诊断，且仅收集价格状态原因会漏掉独立换手缺口。
6. **剩余发布门禁**：全量数据库集成尚无最终通过记录；远端缺此次迁移文件，受保护发布只允许远端主分支。不能用本地直接执行 DDL 替代。

已有验证记录：Python 非数据库测试1311通过、3项平台跳过；新旧监管查询数据库测试15通过，复核SQL再次3通过；Java定向9项、前端13项及两端构建通过。上述是既有执行记录，本轮没有重跑，也不是全量或线上验收通过。

## Global Constraints

- `regulation-monitor.v1` 为系统测算，不是交易所正式认定；正式公告字段未知时为 null。
- 缺失不填0，不伪造行情，不用开盘啦次数替代计算次数，不更改旧接口原义。
- 收盘事件由 Worker 写入；盘中查询不写库、不触发补采或补算。
- 价格使用 Decimal；公开时间沿用 ApiTimestamp；同一响应只使用一个批次。
- 复用现有范围与规则；指数仅 SSE:000002、SZSE:399107、SZSE:399102。
- 候选 limit 1–100；盘中最多50股；总预算8秒；指数情景仅 -2/0/+2%。
- 交易日、适用性、公司行为、行情时效分别验证；缺失的换手口径不从其他股本口径替代。
- 生产迁移仅走受保护流程；测试仅使用可丢弃数据库。
- 已授权新增迁移在剩余验证通过后执行；共享分支推送尚未确认。补数、补算、服务发布/重启、Worker启用分别受原授权边界约束。
- 保留工作区其他修改；不整仓提交、不输出凭据、不增加全市场30秒任务。

## Review Focus

1. 价格历史完整但换手缺失：价格次数可用，换手次数未知；Task 1、2验证。
2. 前一日普通股、目标日变更适用性或次日发生公司行为：必须重查并抑制无依据价格；Task 1、5验证。
3. 历史更正、游标过期和盘中跨日：不拼接旧状态或旧行情；Task 1、5验证。
4. 库里没有新对象、未发布基础，或生产待迁移列表含其他变更：分别报告且不扩大执行；Task 3、4验证。
5. 预检允许部分发布但仍有缺口：`can_execute` 不是全部数据完整；Task 2、4验证并保留缺失股票。

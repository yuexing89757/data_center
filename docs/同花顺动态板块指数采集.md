# 同花顺动态板块指数采集

## 范围

当前只支持 ADR-0003 接受的显式对象：

```text
board_id = THS:883423
name     = 沪深主板昨日涨停
provider = akshare_ths
```

该对象不是可交易 Security，也不写入普通 `core.daily_bar`。

## 首次采集

先保证 Security 和 Trading Calendar 已覆盖目标日期，再按顺序执行：

```bash
market-data-center board-index
market-data-center board-index-daily-bar \
  --start-date 2026-01-01 \
  --end-date 2026-07-29
market-data-center board-index-constituents
```

`--provider` 默认使用自动选择；BoardIndex 当前唯一候选是
`akshare_ths`，需要固定诊断时可显式传入
`--provider akshare_ths`。

## 成分快照语义

同花顺成分页面提供当前完整快照，不提供可证明的任意历史成员。因此
`board-index-constituents` 默认使用 `Asia/Shanghai` 当天日期；即使手工传入
`--snapshot-date`，也必须等于当天。历史成分由每日采集累积，不能事后用当前
响应回填。

建议在交易日收盘后、上游页面完成更新后执行。分页任一请求失败、字段变化、
空响应、未知 Security、重复成员或非交易日都会阻断整个快照写入并留下
IngestionRun、RawManifest 和 QualityResult。

## 幂等与修订

- 板块定义自然键：`board_id`；
- 日 K 自然键：`(board_id, trade_date)`；
- 成分自然键：`(board_id, trade_date, symbol)`；
- `source_code` 不参与重复判断；
- 同日完整成分重跑会在一个事务中替换该日集合；
- Raw 重放创建新的 IngestionRun，但复用并校验原 RawManifest。

## 查询

PostgREST 只读 View：

```text
api_v1.board_indexes
api_v1.board_index_daily_bars
api_v1.board_index_constituents
```

ADR-0035 additionally publishes the fixed, bounded RPC
`api_v1.query_board_index_bias_latest()` and the authenticated FastAPI route
`GET /api/v1/board-indexes/883423/bias`. They select the latest stored board trading day and
calculate MA5, BIAS5, prior-session direction, and latest-30-session extrema at read time. The
query reads at most 34 board bars and is identified by algorithm version
`board_index_bias_v1`; it adds no derived table or Worker schedule. Missing history remains null,
and missing board bars return 404 instead of fetching or substituting data.

客户端不能直接读取 `core`，文档和命令中不得包含数据库连接串或生产凭据。

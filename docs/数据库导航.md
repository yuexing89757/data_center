# 数据库导航

> 版本：对应 migration `20260728000100` … `20260802000700`（共 22 个）
> 生成日期：2026-08-05
> 维护原则：结构只能通过 `supabase/migrations/*.sql` 演进（宪法"Schema 即代码"）

本文档是数据库的索引与地图。每张表给出字段、类型、主键、外键、关键约束与索引；每个 schema 给出职责边界。所有事实均来自 migration，不包含任何未实现提案。

## 全局概览

### Schema 职责一览

| Schema | 职责 | 谁能写 |
|---|---|---|
| `ingestion` | 采集运行元数据、Raw 对象清单 | worker |
| `audit` | 数据质量校验结果 | worker |
| `core` | 证券、交易日历、未复权日K、板块指数、每日指标、扣非利润（客观事实） | worker |
| `capital` | 股本变动、分红、配股（公司行为事实，ADR-0007） | worker |
| `classification` | 分类目录与成分历史（ADR-0008） | worker |
| `derived` | 版本化复权行情、日级指标、市值、涨跌停价/事件、竞价指标（ADR-0009） | worker（重算） |
| `metrics` | 分类层面的日级统计指标（ADR-0009） | worker（重算） |
| `operations` | 调度工作流执行记录（workflow_run / job_execution） | worker |
| `stock_pool` | 主板涨跌停股票池快照与成员 | worker |
| `realtime` | 集合竞价五档行情采集（session/round/snapshot） | worker |
| `api_v1` | 对外只读视图 + 有界 RPC（PostgREST/FastAPI 边界，ADR-0010/0011） | **只读**，无写入 |
| `extensions` | `pgcrypto`、`btree_gist` 扩展 | — |

### 横向约定

- **角色**：`market_data_worker`（nologin，被业务角色继承）持有所有写权限；`anon`/`authenticated`/`authenticator` 只能 select `api_v1`。
- **Provider 枚举**（`ingestion_run.provider_code` / 各表 `source_code`）：`baostock`、`akshare`、`pytdx`、`akshare_ths`、`tushare`、`pytdx_hq`。各表按 ADR-0005 路由限定可用 provider。
- **RLS**：所有数据表都启用行级安全，worker 角色有 `for all using(true)` 策略。
- **`updated_at` 自动维护**：`ingestion.set_updated_at()` 触发器，所有带 `updated_at` 的表在 update 前自动刷新。
- **价格精度**：行情用 `numeric(18,4)`，金额用 `numeric(24,2)`，复权用更高精度 `numeric(28,10)`/`numeric(38,18)`，均不经过 float。
- **可追溯**：几乎所有事实表都有 `source_code`（provider 来源）+ `ingestion_id`（外键到 `ingestion.ingestion_run`）。
- **交易日校验**：日K、板块日K、成分快照都有触发器确保 `trade_date` 必须是已知交易日。

## 1. `ingestion` — 采集运行与 Raw 清单

### `ingestion_run` — 单次采集运行

一次 provider 调用的完整记录（成功/失败/部分）。所有事实表通过 `ingestion_id` 外键指向它。

| 字段 | 类型 | 说明 |
|---|---|---|
| `ingestion_id` | uuid PK | 默认 `gen_random_uuid()` |
| `provider_code` | text | `baostock`/`akshare`/`pytdx`/`akshare_ths` |
| `dataset_code` | text | 见下方枚举 |
| `status` | text | `pending`/`running`/`succeeded`/`failed`/`partial` |
| `requested_at` | timestamptz | 请求时间，默认 `now()` |
| `started_at` | timestamptz | 实际开始（须 ≥ requested_at） |
| `finished_at` | timestamptz | 结束时间，终态必填 |
| `request_params` | jsonb | 调用参数 |
| `fetched_rows` | bigint | 抓取行数 |
| `accepted_rows` | bigint | 接受行数 |
| `rejected_rows` | bigint | 拒绝行数（accept+reject ≤ fetched） |
| `error_summary` | text | 错误摘要 |
| `replayed_from_raw_id` | uuid | 重放来源 Raw 对象（replay 时填，ADR-0006） |
| `created_at`/`updated_at` | timestamptz | 时间戳 |

**dataset_code 枚举**（随领域扩张逐步放宽）：`security`, `trading_calendar`, `daily_bar`, `capital`, `classification_catalog`, `classification_members`, `board_index`, `board_index_daily_bar`, `board_index_constituent_snapshot`

**索引**：`(dataset_code, requested_at desc)`、`(status, requested_at desc)`、`replayed_from_raw_id where not null`

### `raw_manifest` — 不可变 Raw 对象清单

每次采集落盘的原始数据文件（parquet/jsonl）的清单，用于可重放。

| 字段 | 类型 | 说明 |
|---|---|---|
| `raw_id` | uuid PK | |
| `ingestion_id` | uuid FK→ingestion_run | |
| `storage_backend` | text | 仅 `local` |
| `object_path` | text | 相对路径，禁绝对路径/`..` |
| `file_format` | text | `parquet`/`jsonl` |
| `content_sha256` | text | 64 位十六进制，内容指纹 |
| `byte_size` | bigint | ≥ 0 |
| `row_count` | bigint | ≥ 0 |
| `schema_version` | text | Raw schema 版本 |
| `created_at` | timestamptz | |

**唯一**：`(storage_backend, object_path)`　**索引**：`ingestion_id`、`content_sha256`

## 3. `core` — 客观事实

### `security` — 证券主数据

| 字段 | 类型 | 说明 |
|---|---|---|
| `symbol` | text PK | 标准符号 `交易所:代码`，如 `SSE:600000` |
| `code` | text | 6 位数字代码 |
| `exchange` | text | `SSE`/`SZSE`/`BSE` |
| `current_name` | text | 当前名称 |
| `security_type` | text | `stock`/`index`/`etf`/`convertible_bond`/`other`/`unknown` |
| `status` | text | `listed`/`delisted`/`unknown` |
| `ipo_date` | date | 上市日 |
| `delisting_date` | date | 退市日（须 ≥ ipo_date） |
| `source_code` | text | provider 来源 |
| `ingestion_id` | uuid FK | |
| `created_at`/`updated_at` | | |

**约束**：`symbol = exchange || ':' || code`；`(exchange, code)` 唯一；`code ~ '^[0-9]+$'`
**索引**：`status`、`ingestion_id`

### `security_name_history` — 证券曾用名历史

| 字段 | 类型 | 说明 |
|---|---|---|
| `symbol` | text FK→security | |
| `name` | text | 该期间名称 |
| `effective_from` | date PK 组成 | 生效起始 |
| `effective_to` | date | 生效结束（须 ≥ from，null=至今） |
| `source_code`/`ingestion_id` | | 可追溯 |

**关键约束**：GiST `EXCLUDE` 防止同一 symbol 的有效期区间重叠（用 `btree_gist` 扩展）

### `trading_calendar` — 交易日历

| 字段 | 类型 | 说明 |
|---|---|---|
| `market` | text PK 组成 | 固定 `CN_A_SHARE` |
| `trade_date` | date PK 组成 | 自然日 |
| `is_trading_day` | boolean | 是否交易日 |
| `previous_trading_day` | date | 上一交易日（须 < trade_date） |
| `next_trading_day` | date | 下一交易日（须 > trade_date） |
| `source_code`/`ingestion_id` | | |

**索引**：`(market, trade_date) where is_trading_day`（只索引交易日）、`ingestion_id`

### `daily_bar` — 未复权日K（核心行情事实）

| 字段 | 类型 | 说明 |
|---|---|---|
| `symbol` | text FK→security PK 组成 | |
| `trade_date` | date PK 组成 | |
| `market` | text | 固定 `CN_A_SHARE` |
| `open`/`high`/`low`/`close`/`previous_close` | numeric(18,4) | 可空（停牌日） |
| `volume` | bigint | 成交量 |
| `amount` | numeric(24,2) | 成交额 |
| `trade_status` | text | `trading`/`suspended`/`unknown` |
| `is_st` | boolean | 是否 ST |
| `source_code`/`ingestion_id` | | |

**外键**：`(market, trade_date)` → `trading_calendar`（确保是已知市场日）
**触发器**：`ensure_daily_bar_trading_day` 进一步要求 `is_trading_day=true`
**价格约束**：非负；`low ≤ high`；open/close 落在 [low,high]
**索引**：`(market, trade_date)`、`ingestion_id`

> 注：`api_v1.daily_bars` 暴露的就是这张表，**未复权**。复权行情在 `derived`。

### `board_index` — 动态板块指数定义（ADR-0003）

第三方（同花顺）动态板块，与普通证券隔离。

| 字段 | 类型 | 说明 |
|---|---|---|
| `board_id` | text PK | `命名空间:代码`，如 `THS:883423` |
| `board_code` | text | 板块代码 |
| `namespace` | text | 命名空间（如 `THS`） |
| `name` | text | 板块名 |
| `board_type` | text | 固定 `dynamic_theme` |
| `market` | text | 固定 `CN_A_SHARE` |
| `status` | text | `active`/`inactive`/`unknown` |
| `source_code` | text | 固定 `akshare_ths` |

**唯一**：`(namespace, board_code)`

### `board_index_daily_bar` — 板块指数日K

OHLCV 全部 not null（板块指数无停牌），约束与 `daily_bar` 类似。FK 到 `board_index` 和 `trading_calendar`，有 `ensure_board_index_daily_bar_trading_day` 触发器。

### `board_index_constituent_snapshot` — 板块成分快照

| 字段 | 类型 | 说明 |
|---|---|---|
| `board_id` | text FK→board_index PK 组成 | |
| `trade_date` | date PK 组成 | 交易日 |
| `symbol` | text FK→security PK 组成 | 成员证券 |

PK `(board_id, trade_date, symbol)`。THS 只暴露当前成分，历史快照靠每日运行累积（ADR-0003）。

### `stock_daily_indicator` — 每日估值与市场指标（tushare）

单只证券某交易日的估值/换手/市值/涨跌停状态快照。

| 字段 | 类型 | 说明 |
|---|---|---|
| `symbol` | text FK→security PK 组成 | |
| `trade_date` | date PK 组成 | |
| `market` | text | 固定 `CN_A_SHARE`，FK→trading_calendar |
| `close` | numeric(18,4) | 收盘价 |
| `turnover_rate_pct` / `free_float_turnover_rate_pct` | numeric(24,10) | 换手率/自由流通换手率 |
| `volume_ratio` | numeric(24,10) | 量比 |
| `pe` / `pe_ttm` | numeric(24,10) | 市盈率/TTM |
| `pb` | numeric(24,10) | 市净率 |
| `ps` / `ps_ttm` | numeric(24,10) | 市销率/TTM |

| `total_shares` / `circulating_shares` / `free_float_shares` | bigint | 总股本/流通/自由流通（层层 ≤） |
| `total_market_value` / `circulating_market_value` | numeric(30,4) | 总市值/流通市值（流通 ≤ 总） |

> 注：worker 对该表有 delete 权限（`20260802000300` 授予），支持历史回填时的滚动清理。

### `deducted_profit` — 扣非净利润（tushare）

| 字段 | 类型 | 说明 |
|---|---|---|
| `symbol` | text FK→security PK 组成 | |
| `report_period` | date PK 组成 | 报告期 |
| `announcement_date` | date | 预约披露日（须 ≥ report_period） |
| `actual_announcement_date` | date | 实际披露日 |
| `effective_announcement_date` | date | **生成列** = `coalesce(actual, announcement)`，查询用 |
| `cumulative_deducted_profit` | numeric(30,4) | 累计扣非净利润 |
| `quarterly_deducted_profit` | numeric(30,4) | 单季扣非净利润 |
| `update_flag` | text | 修订标记 |

## 4. `capital` — 公司行为基础事实（ADR-0007）

### `share_capital` — 股本变动

| 字段 | 类型 | 说明 |
|---|---|---|
| `symbol` | text FK→security PK 组成 | |
| `effective_date` | date PK 组成 | 生效日 |
| `total_shares` | bigint | 总股本（须 > 0） |
| `restricted_shares` | bigint | 限售股（0..total） |
| `circulating_shares` | bigint | 流通股（0..total） |
| `listed_a_shares` | bigint | A 股流通（0..total） |
| `change_reason` | text | 变动原因 |

### `distribution` — 分红送转

PK `(symbol, report_period)`。`cash_dividend_per_share`/`bonus_share_ratio`/`transfer_share_ratio` 三者至少有一个 > 0（`distribution_has_value`）。`status` ∈ `planned`/`approved`/`implemented`/`cancelled`/`unknown`。

### `rights_issue` — 配股

PK `(symbol, record_date)`。`rights_ratio`（须>0）、`rights_price`（须≥0）、`base_shares`、`proceeds`。配股缴款期 `payment_end_date ≥ payment_start_date`。

## 5. `classification` — 分类与成分历史（ADR-0008）

采用"完整快照 + 有效区间"双模型。分类用上海本地日期快照。

### `catalog_snapshot` — 分类目录快照（某日有哪些分类）

PK `(namespace, classification_type, snapshot_date)`。`classification_type` ∈ `industry`/`concept`/`index`。`definition_count` 该快照包含的定义数。

### `definition_snapshot` — 分类定义快照（单个分类的元信息）

PK `(namespace, classification_type, snapshot_date, classification_code)`。

| 字段 | 说明 |
|---|---|
| `name` | 分类名称 |
| `level` | 层级（> 0） |
| `parent_code` | 父分类代码（自引用 FK，`deferrable initially deferred`，不能自指） |

FK 到 `catalog_snapshot`（`on delete cascade`）。

### `member_snapshot` — 成员快照汇总（某分类某日有多少成员）

PK `(namespace, classification_type, classification_code, snapshot_date)`。`member_count` 成员数。FK 到 `definition_snapshot`（cascade）。

### `member_snapshot_item` — 成员快照明细（某分类某日具体包含哪些证券）

PK `(namespace, classification_type, classification_code, snapshot_date, symbol)`。`symbol` FK→security。FK 到 `member_snapshot`（cascade）。

### `member_interval` — 成员有效区间（历史回溯用）

PK `(namespace, classification_type, classification_code, symbol, valid_from)`。`valid_to` 可空（=至今）。
**关键约束**：GiST `EXCLUDE` 防止同一 (分类,证券) 的区间重叠——保证任意 as-of 查询能唯一定位一条。

## 6. `derived` — 版本化派生计算（ADR-0009）

所有派生表都通过 `calculation_id` 关联到一次计算运行，保证结果可解释、可回溯、可重算。

### `calculation_run` — 计算运行

| 字段 | 类型 | 说明 |
|---|---|---|
| `calculation_id` | uuid PK | |
| `calculation_code` | text | 计算代码（如 `cn_a_share_daily_derived`） |
| `algorithm_version` | text | 算法版本 |
| `mode` | text | `full`/`incremental` |
| `start_date`/`end_date` | date | 计算范围（end ≥ start） |
| `status` | text | `running`/`succeeded`/`failed` |
| `input_watermark` | jsonb | 输入水位（上游数据截止标记） |
| `input_hash` | text | 输入指纹 sha256（64位十六进制） |
| `calculated_at`/`finished_at` | timestamptz | |
| `output_rows` | bigint | 输出行数 |

**唯一索引**：`(calculation_code, algorithm_version, start_date, end_date, input_hash) where status='succeeded'`——同版本+同输入只会有一份成功结果。

### `adjusted_daily_bar` — 复权日K

PK `(calculation_id, symbol, trade_date, adjustment_type)`。`adjustment_type` ∈ `forward`/`backward`，`adjustment_factor > 0`。价格 `numeric(28,10)` 高精度。FK→security，FK→calculation_run（cascade）。

### `daily_metric` — 日级指标

PK `(calculation_id, symbol, trade_date)`。`total_return_1d`、`moving_average_5/10/20`。

### `market_capitalization` — 市值

PK `(calculation_id, symbol, trade_date)`。`total_market_cap`（须≥0）、`circulating_market_cap`。

### `daily_price_limit` — 每日涨跌停价（计算）

PK `(calculation_id, symbol, trade_date)`。FK→calculation_run（无 cascade）。`previous_close`/`upper_limit`/`lower_limit` 均 `numeric(18,4) not null`，约束：`upper > previous_close ≥ lower > 0`、`limit_ratio>0`、`price_tick>0`。带 `is_st`、`rule_version`、`algorithm_version`。

### `price_limit_event` — 涨跌停事件（计算）

PK `(calculation_id, symbol, trade_date, direction)`。`direction` ∈ `up`/`down`。约束：`close = limit_price > 0`（收盘价等于涨停价或跌停价才算封板事件）。

### `auction_quote_metric` — 集合竞价微观指标（派生）

|---|---|---|

| `mid_price` | numeric(18,4) | 中间价 |
| `bid_depth_5` / `ask_depth_5` | bigint | 5 档买/卖深度（≥0） |
| `imbalance_5` | numeric(24,12) | 5 档不平衡度 |
| `seal_amount` | numeric(30,4) | 封单金额（≥0） |
| `algorithm_version` | text | 计算版本 |
| `price_limit_rule_version` | text | 涨跌停规则版本 |

## 8. `operations` — 调度工作流执行

记录调度器（scheduler）触发的工作流及其内部 job 的执行情况，与 `ingestion.ingestion_run`（单次 provider 调用）互补：一个 workflow 可编排多个 job，每个 job 可能产生一次 ingestion。

### `workflow_run` — 工作流运行

| 字段 | 类型 | 说明 |
|---|---|---|
| `workflow_run_id` | uuid PK | |
| `workflow_code` | text | 工作流代码 |
| `scheduled_for` | timestamptz | 计划触发时间 |
| `trigger_source` | text | `scheduled`/`manual`/`recovery` |
| `attempt` | integer | 尝试序号（>0） |
| `status` | text | `running`/`succeeded`/`failed`/`partial` |
| `started_at` / `finished_at` | timestamptz | 运行态 finished 为空，终态必填 |
| `accepted_rows` / `rejected_rows` | bigint | 行数统计（≥0） |
| `error_summary` | text | ≤200 字符 |

**唯一**：`(workflow_code, scheduled_for, attempt)`。

### `job_execution` — 工作流内 job 执行

| 字段 | 类型 | 说明 |
|---|---|---|
| `job_execution_id` | uuid PK | |
| `workflow_run_id` | uuid FK→workflow_run | |
| `job_code` | text | job 代码 |
| `sequence_no` | integer | 序号（>0） |
| `attempt` | integer | 尝试序号（>0） |
| `status` | text | `running`/`succeeded`/`failed`/`partial` |
| `fetched_rows` / `accepted_rows` / `rejected_rows` | bigint | accept+reject ≤ fetched |
| `error_summary` | text | ≤200 字符 |

**唯一**：`(workflow_run_id, job_code, attempt)`。
**索引**：`workflow_run (started_at desc)`、`(status, started_at)`；`job_execution (workflow_run_id, sequence_no, attempt)`、`(status, started_at)`。

## 9. `stock_pool` — 主板涨跌停股票池

基于 `derived.daily_price_limit` / `price_limit_event` 计算出的"昨日主板涨停/跌停"股票池，供次日集合竞价采集使用。版本化、可复现。

### `snapshot` — 股票池快照

| 字段 | 类型 | 说明 |
|---|---|---|

| `basis_trade_date` | date | 计算基准日 |
| `effective_trade_date` | date | 生效日（须 > basis） |
| `version` | integer | 版本（>0） |
| `status` | text | `ready`/`failed` |

## 10. `realtime` — 集合竞价五档行情采集

围绕"集合竞价时段定期采集股票池内证券的五档行情"设计的三层结构：session（一次采集会话）→ round（一轮采样）→ snapshot（单证券单次五档快照）。来源 `pytdx_hq` provider。

### `auction_collection_session` — 采集会话

| 字段 | 类型 | 说明 |
|---|---|---|
| `session_id` | uuid PK | |
| `pool_snapshot_id` | uuid FK→stock_pool.snapshot | 本次采集针对的股票池 |
| `pool_snapshot_version` | integer | 股票池版本（>0） |
| `basis_trade_date` / `effective_trade_date` | date | 基准日/生效日（effective > basis） |
| `window_start` / `window_end` | timestamptz | 采集窗口（end > start） |
| `cadence_seconds` | integer | 采样节奏（1..60 秒） |
| `expected_rounds` / `expected_quotes` | integer/bigint | 预期轮数/报价数（>0） |
| `provider_code` | text | 固定 `pytdx_hq` |
| `status` | text | `running`/`succeeded`/`partial`/`failed` |
| `successful_rounds` / `partial_rounds` / `failed_rounds` | integer | 轮次统计 |
| `successful_quotes` / `failed_quotes` | bigint | 报价统计 |

**唯一**：`(pool_snapshot_id, effective_trade_date, cadence_seconds, provider_code)`。

### `auction_collection_round` — 采样轮次

PK `(session_id, sample_seq)`，FK→session、→ingestion_run。`phase` ∈ `cancellable`/`non_cancellable`/`final_match`（集合竞价三阶段）。约束：`successful_quotes + failed_quotes = expected_quotes`。

### `five_level_quote_snapshot` — 五档行情快照

PK `(session_id, symbol, sample_seq)`。FK→session、→stock_pool.snapshot、→ingestion_run、→raw_manifest、→security。

| 字段 | 说明 |
|---|---|
| `scheduled_at` / `collected_at` / `source_timestamp` | 计划/采集/数据源时间戳 |
| `phase` | `cancellable`/`non_cancellable`/`final_match` |
| `quote_semantics` | `auction_indicative`/`verified_order_book` |
| `quote_status` | `trading`/`suspended`/`closed`/`unknown` |
| `last_price`/`previous_close`/`open`/`high`/`low` | numeric(18,4) |
| `cumulative_volume`/`cumulative_amount` | 累计成交量/额 |
| `bid1..5_price`/`bid1..5_volume`/`ask1..5_price`/`ask1..5_volume` | 五档买卖价量 |
| `source_code` | 固定 `pytdx_hq` |

**索引**：`session (effective_trade_date, started_at desc)`；`round (session_id, scheduled_at)`；`quote (symbol, collected_at desc)`、`(session_id, collected_at, symbol)`。

> `derived.auction_quote_metric` 是基于这些快照计算的派生指标（见 derived 章节）。

## 11. `api_v1` — 对外只读契约（ADR-0010/0011）

**这是唯一对外的 schema**。PostgREST 和 FastAPI 都只读这里。它由视图 + RPC 函数组成，不含任何基表，不做任何写入。

### 视图（直接 select 基表，剥离 `source_code`/`ingestion_id` 等内部字段）

| 视图 | 来源 | 说明 |
|---|---|---|
| `securities` | core.security | 证券列表 |
| `trading_calendar` | core.trading_calendar | 交易日历 |
| `daily_bars` | core.daily_bar | **未复权**日K |
| `share_capital`/`distributions`/`rights_issues` | capital.* | 公司行为 |
| `classification_catalog_snapshots` | classification.definition_snapshot | 分类目录 |
| `classification_member_snapshots` | classification.member_snapshot_item | 成员快照明细 |
| `classification_member_intervals` | classification.member_interval | 成员区间 |
| `calculation_runs` | derived.calculation_run | 计算运行 |
| `adjusted_daily_bars` | derived.adjusted_daily_bar ⋈ calculation_run | 复权日K（只含 succeeded） |
| `daily_metrics`/`market_capitalizations` | derived.* ⋈ calculation_run | 日级指标/市值（只含 succeeded） |
| `classification_daily_metrics` | metrics.* ⋈ calculation_run | 分类统计（只含 succeeded） |
| `board_indexes`/`board_index_daily_bars`/`board_index_constituents` | core.board_index* | 板块指数 |
| `stock_daily_indicators` | core.stock_daily_indicator | 每日估值/换手/涨跌停状态（仅授 authenticated） |
| `classification_member_snapshot_status` | classification.member_snapshot | 成员快照状态（RPC 辅助） |

### RPC 函数（有界查询，5 秒语句超时）

参数错误统一抛 `errcode='22023'`，无快照抛 `P0002`。前 5 个 `security invoker`，后 3 个 `security definer`。

| 函数 | 参数 | 返回 | 边界 |
|---|---|---|---|
| `query_securities` | `p_query`, `p_limit≤100` | 证券列表 | 模糊匹配 symbol/code/name，按精确度排序 |
| `query_daily_bars` | `p_symbol`, 日期范围, `p_limit≤5000` | 未复权日K | symbol 须 `^(SSE\|SZSE\|BSE):[0-9]{6}$`；范围 ≤ 3661 天 |
| `query_recent_daily_bars` | 六位 `p_code`, 截止 `p_trade_date`, `p_limit≤5000` | FastAPI 最近未复权日K | Security 唯一解析 symbol；倒序；缺失交易日不补造；仅 `market_data_api` |
| `query_adjusted_daily_bars` | symbol, 日期, `p_adjustment_type`, `p_algorithm_version`, `p_calculation_id?`, limit | 复权日K | 自动选兼容版本；无兼容版本抛 P0002 |
| `query_market_snapshot` | `p_trade_date`, version, calc_id?, limit | 某日全市场快照（raw+metrics+cap） | 版本一致性同上 |
| `query_classification_members_as_of` | namespace, type, code, `p_as_of_date`, limit | `(snapshot_date, member_count, returned_count, members jsonb)` | 取 ≤ as_of 的最新完整快照 |
| `query_deducted_profits_as_of` | `p_as_of_date`, `p_symbols?`, `p_limit≤2000` | 每只证券截至该日的最新扣非利润（distinct on symbol） | 按 effective_announcement_date 降序取最新修订 |
| `query_stock_pool_snapshot` | `p_pool_code`, `p_effective_trade_date`, `p_version?`, `p_limit≤5000` | jsonb：快照元信息 + 成员明细（含行情/指标） | 须精确命中 ready 快照；否则 P0002 |
| `query_limit_up_pool` | `p_trade_date`, `p_version?`, `p_limit≤5000` | jsonb：精确 basis 日期主板涨停池；名称按日，`free_float_market_cap_cny=close×free_float_shares` | 缺失输入逐行省略并按原因计数；有效行按 symbol 排序后限量，不回退日期或市值字段 |
| `query_auction_quotes` | `p_trade_date?`/`p_session_id?`/`p_symbol?`/时间窗?, `p_limit≤5000` | 集合竞价五档行情（买卖档聚合成 jsonb） | symbol 须 `^(SSE\|SZSE):[0-9]{6}$`；时间窗 ≤ 1 天 |
| `query_call_auction_market_snapshots` | `p_trade_date`, `p_codes`（1～500 个六位代码） | jsonb：单一成功批次，或无成功批次时的最新 partial 批次 | 代码去重；不拼批次、不回退日期；显式返回缺失代码 |

> FastAPI（ADR-0011）只调用这里列出的受限 RPC。复权与日级衍生市场快照 RPC 保留但 FastAPI
> 暂未暴露；09:26 集合竞价全市场来源事实仅通过精确日期、最多 500 个代码的新 RPC 批量读取。

## 关系速查：可追溯链路

```
provider 采集
   │
   ▼
ingestion.ingestion_run (ingestion_id, provider_code, dataset_code)
   │                                     │
   ├─► ingestion.raw_manifest            │ (Raw 对象，sha256 指纹)
   │                                     │
   └─► audit.quality_result              │ (质量校验)
                                         │
   每张事实表都带 source_code + ingestion_id ┘
         │
         ▼
   core / capital / classification (客观事实)
         │
         │ (给定相同输入可重算)
         ▼
   derived.calculation_run (calculation_id, algorithm_version, input_hash)
         │
         └─► derived.adjusted_daily_bar / daily_metric / market_capitalization
             metrics.classification_daily_metric
                   │
                   ▼ (只读，剥离内部字段)
              api_v1.*  ──► PostgREST / FastAPI ──► 消费者
```

## 常用查询入口

**查某只股票最新行情采集状态：**
```sql
select status, finished_at, accepted_rows, rejected_rows, error_summary
from ingestion.ingestion_run
where dataset_code = 'daily_bar' and status in ('succeeded','failed','partial')
order by finished_at desc limit 5;
```

**查某日全市场未复权日K（通过 api_v1）：**
```sql
select * from api_v1.daily_bars where trade_date = '2026-08-04' limit 5;
```

**查某分类在某日的成员（通过有界 RPC）：**
```sql
select * from api_v1.query_classification_members_as_of(
    'THS','industry','BK0475','2026-08-04', 5000
);
```

**查最新成功的复权计算版本：**
```sql
select calculation_id, algorithm_version, start_date, end_date, calculated_at
from api_v1.calculation_runs
where calculation_code = 'cn_a_share_daily_derived' and status = 'succeeded'
order by calculated_at desc limit 1;
```

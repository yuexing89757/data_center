# 09:26 沪深主板一字涨跌停实时计算领域详设

## 读取边界

入口为 `GET /api/v1/call-auction-one-price-limits?trade_date=`。唯一来源事实是
`realtime.call_auction_market_snapshot` 在 Asia/Shanghai `09:25:50`（含）到 `09:30:00`（不含）
的批次。显式日期精确查询且不回退；省略日期选择最新符合窗口的交易日。同日按 succeeded 优先、
partial 兜底，并保留选中 ingestion 的 UUID 和状态。

查询由 `api_v1.query_auction_one_price_limits(date)` 完成，函数为 stable、security definer、
statement timeout 5 秒，只授权 `market_data_api`。它不写入任何 schema，不访问行情 Provider，
不触发 Worker 或定时任务。

## 沪深主板范围

- SSE：`600000..603999`、`605000..605999`；
- SZSE：`000001..004999`，排除 `001001..001199`；
- `security_type=stock`、`status=listed`；
- 创业板、科创板、北交所、基金、债券不进入 `candidate_count`，也不计遗漏。

IPO 日期必须存在，目标日的上市交易日序号必须大于 5，且目标日前五个交易日均有
`trading`/`unknown` 日 K，才能证明已经离开无涨跌幅限制阶段。主板代码满足但上市阶段、名称或
报价证据不完整的记录计入 `omitted_incomplete_count`。

## 价格规则与分类

价格全程使用 PostgreSQL numeric：

```text
raw_upper = round(previous_close * 1.10, 2)
upper_limit = previous_close + 0.01  if abs(raw_upper - previous_close) < 0.01 else raw_upper
raw_lower = round(previous_close * 0.90, 2)
lower_limit = max(previous_close - 0.01 if abs(raw_lower - previous_close) < 0.01 else raw_lower, 0.01)
```

普通股和 ST 股均保持 10%，档位 0.01 元。规则版本是 `CN_MAINBOARD_2026_07_06`，算法版本是
`1.0.0`。昨收、现价、最高、最低必须完整且为正数。

- `last_price = high_price = low_price = upper_limit`：一字涨停；
- `last_price = high_price = low_price = lower_limit`：一字跌停；
- 证据完整但价格未严格命中：合法非成员，不计遗漏。

不读取目标日收盘日 K，不从其他日期或其他 ingestion 拼接事实。

## 返回与错误

响应返回上下列表、候选/遗漏/命中计数和每项来源字段，同时返回：

```text
price_limit_calculation_id=null
price_limit_rule_version=CN_MAINBOARD_2026_07_06
price_limit_algorithm_version=1.0.0
calculation_mode=realtime_read
```

快照存在但列表为空时返回 200。没有可用 09:25:50 快照时 RPC 抛出 `P0002`，FastAPI 映射为 404。
数据库或 RPC 不可用映射为 503，API Key 无效为 401。

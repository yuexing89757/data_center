# 同日跌停快照领域详设

## 范围、主键及事实来源

- 市场日历为 `CN_A_SHARE`，时间为 Asia/Shanghai。仅纳入 ADR-0021 沪深主板规则已覆盖证券。
- `today_limit_down.snapshot` 自然键 `(trade_date, version)`；`member` 自然键
  `(snapshot_id, symbol)`；来源观察按 `(ingestion_id, symbol)` 唯一。
- 成员须同时属于 `basis_trade_date = trade_date` 的最新 ready 跌停池，且
  `core.daily_bar.close` 精确等于 `derived.daily_price_limit.lower_limit`。
  来源名单不是成员资格依据。
- 历史名称取同日有效的 `core.security_name_history`；前收和收盘取同日日 K；
  `free_float_shares` 取同日每日指标；`free_float_market_cap_cny = close * free_float_shares`。
  `change_percent = round((close / previous_close - 1) * 100, 10)`。

## 来源观察与收盘盘口

- AKShare/EastMoney 跌停池只映射来源名称、末次封板时间、开板次数、连续跌停天数、
  来源报告封单资金。首次封板时间不可得，保持 NULL；累计封板时长也保持 NULL，
  `duration_semantics='unavailable_without_event_stream'`。
- 来源价格、涨跌幅、流通市值、名称不能覆盖规范事实。Raw/ingestion ID 保存在来源观察，
  成员只冻结对应来源观察的可空血缘。
- 21:10 收盘五档任务按同一 `basis_trade_date` 选择 ready 涨停池与跌停池各自最新版本，
  缺任何一池即失败；对两池成员去重后只请求一次。已有涨停 bid-1 封单额只针对涨停池。
  跌停成员冻结 ask-1 至 ask-5 价量。只有 ask-1 价量完整且 ask-1 价格精确等于跌停价时，
  `closing_ask1_sealing_amount_cny = ask1_price * ask1_volume`；其他情况为 NULL。
- 价格 `numeric(18,4)` 元/股；比例 `numeric(24,10)` 百分点；股数 `bigint` 股；
  金额 `numeric(30,4)` 元。全链路使用 Decimal，不经 float。

## 质量与版本

- 缺必需上游封存 deferred，不请求来源；同日上游 partial、成员缺规范事实或缺个别来源
  观察封存 partial。缺个别来源观察时保留规范成员，来源字段为 NULL。
- 来源整体失败封存零成员 failed，保留失败 ingestion/任务及质量原因。缺盘口保留成员，
  卖盘字段 NULL 并记录 warning。来源空结果与网络/结构错误必须区分。
- 同一输入哈希重跑返回已有版本；上游、来源或盘口修订生成新版本。
  快照和成员只插入不更新。`content_hash` 覆盖排序后的成员，`input_hash` 覆盖精确输入血缘。

## Worker 与 API

- `today-limit-down-snapshot-daily` 为 Worker 内 APScheduler 周一至周五 22:10 固定任务，
  必须核验交易日；仅提供启停开关，默认停用。手工命令需显式 `--trade-date`。
- `GET /api/v1/daily-limit-down-list` 只读精确 `trade_date`，可选 `version`；
  `offset` 范围 0..50000、`limit` 范围 1..500，默认 200，按 symbol 升序。
  不存在的精确日期或版本返回 not_found，不回退。公开状态、版本、哈希、计数、
  质量摘要、来源及规范事实血缘和全部成员字段。Decimal 转十进制字符串；
  时间格式为上海时区 `YYYY-MM-DD HH:mm:ss`，可空事实保持 null。
- FastAPI 只能执行受限 `api_v1` RPC，不接触内部表。生产迁移及部署需独立授权。

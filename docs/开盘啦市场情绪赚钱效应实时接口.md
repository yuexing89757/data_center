# 开盘啦市场情绪赚钱效应实时接口

## 接口

`GET /api/v1/realtime/kaipanla/market-emotion/money-effect`

接口在请求时读取开盘啦首页“市场情绪 → 赚钱效应”历史列表，只返回列表中已验证的三项事实：
日期、打板成功率和打板盈利率。不读取“展开”详情，不写 PostgreSQL 或 Raw，不触发 Worker。

请求需要 `X-API-Key`。查询参数：

- `offset`：来源列表偏移，默认 `0`，范围 `0..10000`。
- `limit`：本页最大条数，默认 `20`，范围 `1..100`。

服务每次请求只访问一页上游数据，不重试、不自动翻页。上游没有可靠总数，因此 `total` 固定为
`null`；本页满页时返回 `next_offset`，短页时为 `null`。结果严格保持日期倒序。

## 响应示例

```json
{
  "source_code": "kaipanla",
  "source_layout": "kaipanla.market_emotion.money_effect.v1",
  "persisted": false,
  "observed_at": "2026-09-27 20:02:03",
  "offset": 0,
  "limit": 20,
  "returned_count": 2,
  "total": null,
  "next_offset": null,
  "items": [
    {
      "trade_date": "2026-09-24",
      "board_success_rate_pct": "50.00",
      "board_profit_rate_pct": "0.55"
    },
    {
      "trade_date": "2026-09-23",
      "board_success_rate_pct": "48.72",
      "board_profit_rate_pct": "-0.88"
    }
  ]
}
```

两个比例字段都使用百分比数值而非小数比率，例如 `50.00` 表示 `50.00%`。数值使用 Decimal
精确解析并按字符串输出。来源返回非 JSON、失败码、非法日期、非有限数值、成功率越界、重复日期
或非倒序数据时，接口返回通用 `502 upstream_error`，不会泄露来源响应。

## 数据边界

该接口是请求时的第三方实时只读适配，不是可重放的持久化事实。`observed_at` 仅表示本服务收到
该页响应的时间，并按上海时区输出为 `YYYY-MM-DD HH:mm:ss`。上游字段或可用性变化可能导致
502；接口不会用数据库旧数据兜底。

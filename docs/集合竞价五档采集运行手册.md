# 集合竞价五档采集运行手册

任务 `opening-auction-limit-up-quotes` 默认关闭。它在交易日 09:15 启动一个会话，
内部每 5 秒采样，至 09:25 最终一轮；不会创建上百个 APScheduler job。

## 启用前预检

先应用 migration 到隔离环境，并确认 Worker 启动刷新已生成至少一个具备 `quote` 能力的
PYTDX 节点。只读预检不连接行情服务器，也不写数据库：

```bash
uv run market-data-center auction-quotes-preflight --trade-date 2026-08-03
```

报告必须确认交易日、当日精确 ready 涨停池、成员数和期望 121 轮。禁止回退旧股票池。

## 下一交易日 live gate

在真实 09:15–09:25 窗口核对沪深代码映射、价格单位、手转股数量、累计成交额、
09:20 阶段边界、每批最多 80 只、单轮耗时低于 5 秒，以及重试不会越过下一采样点。
同时确认集合竞价返回档位是否具备标准连续五档语义。未通过前，任务保持
`AUCTION_COLLECTION_ENABLED=false`，派生 spread/depth/imbalance/seal amount 保持 NULL。

通过门禁后才显式配置：

```text
AUCTION_COLLECTION_ENABLED=true
AUCTION_COLLECTION_CADENCE_SECONDS=5
```

进程崩溃后只恢复当前及未来采样点；过去采样点记录为缺失，不允许补造。公开读取使用
authenticated PostgREST RPC `api_v1.query_auction_quotes`，请求必须带精确交易日或 session ID，
最多返回 5000 条。

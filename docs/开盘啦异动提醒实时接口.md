# 开盘啦异动提醒实时接口

已接入现有 `market-data-api` FastAPI 应用，Swagger 分类为 **实时接口**。
所有请求要求 `X-API-Key`。请求时读取开盘啦，不写数据库、不保存 Raw、不触发调度。
无需数据库迁移；应用启动仍遵循现有 `FASTAPI_DATABASE_URL` 等配置要求。

## 路由

前缀 `/api/v1/realtime/kaipanla/alerts`，日期格式 `YYYY-MM-DD`。

|方法|后缀|参数|用途及上游 action|
|---|---|---|---|
|GET|`/severe`|可选 `trade_date`|严重异动当日/次日；当前 `GetPianLiZhi_W46` / 历史 `GetYDTPZFPL_W46`|
|GET|`/severe/history`|必填 `trade_date`；`offset=0`、`limit=20`、`filter=all`|近期严重异动分页；`GetYDTPZFPL_W46_HisAll`|
|GET|`/hot`|可选 `trade_date`|热门股偏离值；`GetPianLiZhi_Hot` / `GetPianLiZhi_Hot_His`|
|GET|`/monitor`|无|当前重点监控；`GetYDTP_ZDJK_Today`|
|GET|`/monitor/history`|可选 `before_date`|监控历史；HQ 首批 / HIS 继续加载 `GetYDTP_ZDJK_His`|
|GET|`/inquiries`|无|问询函首批；HQ `GetYDTP_WXHJ_His`|
|GET|`/inquiries/history`|`offset=0`、`limit=20`|问询函分页；HIS `GetYDTP_WXHJ_His`|
|POST|`/quotes/query`|JSON `{"codes":["600127","001216"]}`|现价刷新；`UserSelectStock/RefreshStockList_price`|
|GET|`/legacy`|可选 `trade_date`、`triggered_only=false`|旧偏离值；`GetPianLiZhi_Index` / `GetPianLiZhi_Index_W32`|
|GET|`/multiple`|无|多次异动；`GetPianLiZhi_Many`|

10 个路由覆盖 14 种只读上游请求，账户设置读写不在范围内。上游 GET/POST 和 HQ/HIS
选择由 Provider 处理。历史参数也属于请求时读取，不保存查询结果。

## MuMu 页面与来源请求核对（2026-09-29）

在本机 MuMu 的开盘啦首页，依次打开了“严重异动提醒 → 更多”“查看多次异动个股”
和“重点监控与问询函 → 重点监控”。下表的**页面结构**来自模拟器现场观察；
**HTTP 方法、域名、action 和参数**来自本项目现有 Provider，并用同一 Provider 对来源做了只读请求验证。
本次没有对模拟器安装抓包证书或拦截其 HTTPS 流量，因此不把代码映射称为 App 网络抓包结果。

来源地址固定为 `https://apphwshhq.kaipanla.com/w1/api/index.php`（HQ）和
`https://apphis.kaipanla.com/w1/api/index.php`（HIS）。除表中差异参数外，请求均带
`c=StockBidYiDong`、`apiv=w48`、`PhoneOSNew=1`、`VerSion=6.3.20.0`、`Red=0`；
GET 放在查询串，POST 使用 `application/x-www-form-urlencoded` 请求体。`a` 是下表的 action。

| MuMu 页面/操作 | 已有来源请求映射 | 主要来源列表键 | 本项目只读接口 |
|---|---|---|---|
| 首页严重异动提醒、更多页当日/次日 | HQ GET `GetPianLiZhi_W46` | `List_Today` / `List_Tormorow` | `GET /severe` |
| 更多页指定历史日期 | HIS GET `GetYDTPZFPL_W46`，`Day=YYYY-MM-DD` | `List_Today` / `List_Tormorow` | `GET /severe?trade_date=...` |
| 更多页历史列表及“全部/只看严重异动”筛选 | HIS GET `GetYDTPZFPL_W46_HisAll`，`Day`、`Index`、`st`、`IsZT`；停牌筛选另带 `Status=1` | `List_His`、可选 `List_His_Total` | `GET /severe/history` |
| 查看多次异动个股，沪深主板/创业·科创板两个页签 | HQ POST `GetPianLiZhi_Many` | `List` | `GET /multiple` |
| 重点监控页的“监管期证券” | HQ POST `GetYDTP_ZDJK_Today` | `List` | `GET /monitor` |
| 重点监控页的“历史监管期证券” | HQ POST `GetYDTP_ZDJK_His` 首批；HIS POST 同 action 并带 `Day` 日期游标继续加载 | `List` | `GET /monitor/history` |

现场页面显示：严重异动更多页按日期分组，提供“全部/只看严重异动”；多次异动页分别展示
沪深主板和创业/科创板，并列出偏离值、预计异动价格、当前价格；重点监控页同时列出监管期内
及历史股票的开始/结束日期和类别。2026-09-29 的只读来源响应中，严重异动当日 1 行、
多次异动 `List` 16 行（14 只不同代码，同一股票可以占多行）、当前重点监控 3 行。
这些数量仅用于对应当次页面，不保证后续不变。监控历史页的逐条加载请求未在模拟器中抓包确认，
其 HQ/HIS 映射只代表当前项目实现；页面展示的历史行数也未与该接口逐行核对。

`GetPianLiZhi_Many` 的已观察来源行有 11 列。将主板 `001216` 和科创板 `688004`
的来源行与 MuMu 列表对照，确认下标 0/1 为代码/名称、6 为偏离值百分比、7 为预计异动价格、
8 为该价格对应的预计涨幅百分比、9 为当前价格、10 为当前涨跌幅百分比；这些仍保存在
`source_values`；本次已补充具名字段，见下方“异动监控具名字段”。下标 2–5 的完整枚举和规则含义未核实，
不能仅凭页面标题推断。重点监控来源行的
下标 2/3 是开始/结束日期，第 4 列页面展示为类别，本项目尚未把类别转换为有名字段。
“问询函”是同一页面的另一个页签，不属于本次三个目标之一；其接口见上表路由说明。

`filter` 为 `all`（全部）、`triggered`（已触发）、`suspended`（被停牌），内部转换来源参数。
分页 `limit` 1–20、`offset` 0–10000，不自动全量翻页。现价请求最多 100 个六位代码，按首次出现
顺序去重。监控的 `before_date` 为加载日期游标，不保证精确日期查询。

## 统一响应

### 2026-09-29：异动监控具名字段

现有 `/severe`、`/multiple` 路由增量返回以下字段，无新增数据库、任务或路由。
这些仍是开盘啦来源信息，不是 Regulation 的交易所正式事件或规则计算。

| 字段 | 来源和口径 |
|---|---|
| `rule_description` | 严重异动的来源规则文字；多次异动的来源分组说明，保留原文 |
| `trigger_status` | 严重异动 today 分组第8列状态原文；tomorrow 不伪造已触发状态 |
| `today_trigger_change_pct / today_trigger_price` | severe today 第5/6列，百分比/元 |
| `tomorrow_trigger_change_pct / tomorrow_trigger_price` | severe tomorrow 第5/6列，百分比/元 |
| `source_abnormal_count_10d` | multiple 第3列文字完整匹配“10日内N次异动个股”时提取N；未提供为null |
| `deviation_pct` | multiple 第6列偏离值百分比 |
| `expected_trigger_price / expected_change_pct` | multiple 第7/8列预计异动价/涨幅；来源没有明确日期，不归入今日或次日 |

multiple 第9/10列补充 `last_price/change_pct`。severe 第19列为价格；today 第3列为当前涨幅。
tomorrow 第3列可能是占位零，不作为当前涨幅；需要现价时使用 `/quotes/query`。
规则文字取 severe today 第2列、tomorrow 第12列。

字段依据：现有 APP 6.3.20.0 的 `SevereAbnormalPresenter`、`ar0.b/c` 数组转换和
`SevereAbnormalFragment` 列标题绑定，结合请求时返回的行布局核对；非本轮 App 页面抓包。
特别注意，第9列在 APP 绑定为“次日触发异动偏离值空间”，不是次日涨幅；第13列未在上述
页面绑定中确认，不转换为次日价格。严禁将它们作为今日记录缺失的次日门槛。

仅识别已核对的 severe 20列、multiple 11列布局；短行或未知长度仍保留原行，新增字段为null。
未提供次数不等于零，也不从其他数字枚举或交易所公告补齐。跨接口关联次数时必须匹配代码和
来源数据日期；同一代码多行的次数不能相加。今天/次日均相对来源交易日，刷新不改变历史日期。
目前热门偏离列表未提供已确认的触发价字段，调用方应显示缺失，不自行套用 severe 的数组布局。

|字段|含义|
|---|---|
|`source_code` / `persisted`|固定 `kaipanla` / `false`|
|`source_layout`|数组布局版本，例如 `kaipanla.alerts.severe.v1`|
|`observed_at`|收到响应的上海时间，`YYYY-MM-DD HH:mm:ss`|
|`source_timestamp`|上游 Time 转换的上海时间，不一定是行情时间；未提供时 null|
|`requested_date`|调用方日期；监控历史为日期游标；未传则 null|
|`trade_date`|来源实际数据日期；未提供时 null，不拿请求日期或自然日补填|
|`date_matches_request`|两日期皆存在才比较，否则 null；旧历史接口可能 false|
|`groups`|统一列表分组，每组包含 `key`、`items`|
|`offset / limit / total / next_offset`|分页元数据；没有来源总数则 total=null，满页仅提示可以继续请求|
|`next_date`|监控历史继续加载日期；没有可用的向前游标时 null|
|`missing_codes`|现价请求中未返回的代码；其他接口为空数组|

严重异动分组为 `today`、`tomorrow`，历史分页为 `history`，普通列表为 `items`；旧主页另外有
`monitor`、`inquiries`。today/tomorrow 相对来源交易日，不是服务器自然日。

每行有 `symbol`、`code`、`name`，并提供已确认字段：

- 现价刷新：`last_price`（元）、`change_pct`（百分比）。来源不提供名称，name=null。
- 重点监控：`start_date`、`end_date`。
- 问询函：`announcement_date`、`document_url`（仅返回链接，不下载）。
- 缺失或不适用字段为 null，零值仍为零。无效日期哨兵 `0000-00-00` 转为 null。

小数为 Decimal 并以 JSON 字符串输出，如 `"16.49"`、`"-1.55"`；整数仍为整数。

### 尚未确认的列

`source_values` 保留完整来源行，是这组开盘啦专属接口的明确来源字段例外，**不属于标准指标**。
不得把不同布局同一下标解释为同一指标，不得当作 Regulation 官方事实。

|source_layout 后缀|已确认的原行下标（从 0 开始）|
|---|---|
|`severe.v1 / multiple.v1`|0 代码、1 名称；具名字段和已确认布局见上节，其余列不猜测|
|`hot.v1 / legacy.v1`|0 代码、1 名称；其余列未命名|
|`monitor.v1`|0 代码、1 名称、2 监控开始、3 监控结束；后续枚举含义未完全确认|
|`inquiry.v1`|0 代码、1 名称、2 公告日期、3 文档链接；后续枚举含义未完全确认|
|`quote.v1`|0 代码、1 最新价（元）、2 涨跌幅（百分比）|

旧版主页附加 monitor/inquiries 分组只有身份行（0/1），不能套用完整监控/问询函行。

## 错误和运行

复用错误格式：`{"error":{"code":"upstream_error","message":"Kaipanla alert provider request failed"}}`。

- 401：缺少或错误的 API key。
- 422：非法日期、代码、分页或筛选参数。
- 502：网络失败、超时、业务错误、非 JSON 或异常响应结构。
- 仅上游成功且明确给出空列表时，返回 200 空数据。

可选 `FASTAPI_KAIPANLA_TIMEOUT_SECONDS=8`，范围 1–10 秒，是网络操作超时而非整体响应 SLA。
响应最大 2 MB，不重试；固定域名、禁用重定向、直连且不使用系统代理。

启动现有服务后在 `/docs` 的“实时接口”测试，或：

```bash
curl -H "X-API-Key: $FASTAPI_API_KEY" \
  "http://127.0.0.1:8000/api/v1/realtime/kaipanla/alerts/severe"

curl -H "X-API-Key: $FASTAPI_API_KEY" \
  "http://127.0.0.1:8000/api/v1/realtime/kaipanla/alerts/severe/history?trade_date=2026-09-23&filter=triggered&offset=0&limit=20"

curl -X POST -H "X-API-Key: $FASTAPI_API_KEY" -H "Content-Type: application/json" \
  -d '{"codes":["600127","001216"]}' \
  "http://127.0.0.1:8000/api/v1/realtime/kaipanla/alerts/quotes/query"
```

# 领域详设：Capital v1

## 1. 边界

Capital 保存股本结构和公司行为输入事实，依赖 Security 的统一 `symbol`。它不保存行情、不生成复权价格，也不把当前快照倒填成历史。

## 2. ShareCapital

| 字段 | 类型/单位 | 约束 |
| --- | --- | --- |
| `symbol` | text | Security 外键 |
| `effective_date` | date | 生效日；与 symbol 构成自然键 |
| `total_shares` | bigint/股 | 大于 0 |
| `restricted_shares` | bigint/股 | 可空，0 到总股本 |
| `circulating_shares` | bigint/股 | 可空，0 到总股本 |
| `listed_a_shares` | bigint/股 | 可空，0 到总股本 |
| `change_reason` | text | 可空的标准描述 |
| `source_code` | text | 追溯，不参与自然键 |

## 3. Distribution

一行表示一个报告期的组合分配方案，可同时包含现金、送股和转增。自然键是 `(symbol, report_period)`。现金单位为元/股，送转单位为新增股/原股。三种分配值至少一项大于 0；“不分配”方案不进入 Core，但仍保留在 Raw。

方案保留 `announcement_date`、`record_date`、`ex_date` 和 `status`。状态统一为 `planned`、`approved`、`implemented`、`cancelled`、`unknown`。

## 4. RightsIssue

自然键是 `(symbol, record_date)`。配股比例为新增股/原股，配股价格为元/股；登记日和比例必填。公告日、除权日、缴款期、上市日、基准股本和募集金额可空；1900 占位日期转换为 `NULL`，缴款结束日不得早于开始日。

## 5. 修订与冲突

数据库按自然键 UPSERT。新批次覆盖当前标准事实并更新 `source_code`、`ingestion_id`；历史 Raw 和 IngestionRun 不变。单批次若同一自然键出现不同内容，整组事实拒绝写入并产生 `capital.conflicting_duplicate`；未知 Security 产生 `capital.unknown_symbol`。

## 6. Provider 与 Raw

AKShare Adapter 把三个上游表合并成 `akshare.capital.v1` JSONL，并用仅存在于 Raw 的 `_capital_record_type` 区分记录类型。该标签和中文列名止于 Adapter/Normalizer 边界。重放按 `provider_code + dataset_code + schema_version` 恢复相同 DTO。

## 7. CLI

```bash
market-data-center capital --source-symbol SSE:600000 --mode backfill
market-data-center capital --source-symbol SSE:600000 --mode incremental
```

AKShare 端点不支持日期过滤，两种模式均抓取完整历史并幂等对账；`mode` 写入请求参数供审计和调度区分。

## 8. PostgREST

`api_v1.share_capital`、`api_v1.distributions` 和 `api_v1.rights_issues` 只暴露业务字段，不公开来源、批次和内部时间戳。Core 表启用 RLS；Worker 可写，API 角色只读 View。

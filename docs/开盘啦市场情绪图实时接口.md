# 开盘啦市场情绪图实时接口

`GET /api/v1/realtime/kaipanla/market-emotion/chart?offset=0&limit=100`

需要 `X-API-Key`。请求时读取开盘啦“首页 → 市场情绪 → 涨跌统计 → 更多”的历史图表数据。
`offset` 默认 0，范围 0–10000；`limit` 默认 100，范围 1–100。结果按交易日期倒序，
绘图时调用方可按日期正序展示。满页返回可尝试的 `next_offset`，短页返回 null；总数未知。

每行字段：

| 字段 | 含义 |
| --- | --- |
| trade_date | 来源交易日期，YYYY-MM-DD |
| emotion_index | 来源情绪指标，0–100 整数 |
| large_drawdown_count | 来源大幅回撤股票家数 |
| limit_up_count | 来源图表口径涨停家数 |
| consecutive_limit_up_height | 来源连板高度，单位板 |

这些值直接来自开盘啦，不是本系统计算的指标。大幅回撤判定和涨停统计采用来源口径，
不可假定与本系统股票池相同。响应不包含来源的投资提示文本。

固定上游为 `https://apphis.kaipanla.com/w1/api/index.php`，POST 参数
`c=HisHomeDingPan&a=ChangeStatistics&Index=<offset>&st=<limit>`。
来源字段 `Day/strong/df_num/ztjs/lbgd` 在适配器内转换为上述标准字段。
APP 历史图表读取此 HTTP 接口；本接口不接入 APP 当日 Socket 2111 推送。

每个请求只读取一页，无登录凭据、重试、自动翻页、重定向或系统代理；超时复用
`FASTAPI_KAIPANLA_TIMEOUT_SECONDS`，响应上限 2 MB。不访问数据库，不保存 Raw，不触发 Worker。
无可靠总数时 `total=null`，`persisted=false`。`observed_at` 使用上海时区
`YYYY-MM-DD HH:mm:ss`，表示本服务收到响应的时间，不是行情发生时间。

上游网络故障、错误码、无效日期、缺失字段、非法计数、重复/非倒序日期或超限响应返回
502 `upstream_error`，不会包装成空列表。参数错误 422，鉴权失败 401。

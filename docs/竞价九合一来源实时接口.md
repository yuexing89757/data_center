# 竞价九合一来源实时接口

日期2026-10-13；[ADR-0067](adr/ADR-0067-竞价九合一来源实时只读接口.md)；[Issue #89](https://github.com/yuexing89757/data_center/issues/89)。

所有公共路由为GET，位于Swagger `/docs` 的“实时接口”，要求`X-API-Key`。
每次请求只读取一次上游，不入库/Raw、不触发Worker、不缓存、不自动分页、重试或跨源兜底。
历史K线属于请求时读取模式，“实时接口”不等于9:25竞价快照。
getExpectHot、CDN、网页跳转、模拟数据、本地策略/随机AI评分均不接入。

完整curl示例（Windows使用curl.exe）：

```bash
curl -G 'http://127.0.0.1:8000/api/v1/realtime/tencent/minute' \
  -H 'X-API-Key: <你的API Key>' --data-urlencode 'symbol=SSE:600000'
curl -G 'http://127.0.0.1:8000/api/v1/realtime/eastmoney/limit-up' \
  -H 'X-API-Key: <你的API Key>' --data-urlencode 'trade_date=2026-10-12' \
  --data-urlencode 'page=1' --data-urlencode 'page_size=500'
```

PowerShell：

```powershell
$sourceHeaders = @{ 'X-API-Key' = '<你的API Key>' }
Invoke-RestMethod -Headers $sourceHeaders -Uri 'http://127.0.0.1:8000/api/v1/realtime/tencent/minute?symbol=SSE%3A600000'
```

| 参数 | 类型/范围 | 默认与例子 | 适用接口 |
|---|---|---|---|
| market | all/mainboard/star/growth | all；mainboard沪深主板、star科创、growth创业 | 行情 |
| page | 整数1～100 | 1；显式下一页传2 | 行情、池、题材排行/成分 |
| page_size | 行情1～6000、池1～500、题材1～100、成分1～1000 | 分别5000/500/100/1000 | 分页列表 |
| trade_date | 必填有效YYYY-MM-DD，不得未来 | 2026-10-12；不自行移动节假日 | 三类池 |
| trade_date | 可选有效YYYY-MM-DD，不得未来 | 作为含当日的上游end；省略沿用20500101 | 东财日K |
| symbol | 必填SSE:6开头或SZSE:0/3开头股票代码 | SSE:600000、SZSE:000001 | 分时/K线 |
| limit | 整数1～640 | 160；谛听/尾盘120、黑马60、猎手历史10或图640 | K线 |
| period | day/week | day，原猎手界面主要day | 腾讯K线 |
| server | web/ifzq | web；综合原主源ifzq | 腾讯K线 |
| theme_code | 路径字符串，1～32位数字/英文字母 | 00647保留前导零 | 成分股 |

K线/分时暂不支持BSE；行情只开放原四种沪深市场，不开放猎手旧三板fs=m:0+t:13。
不接受任意URL、UT、来源fields、请求体或JSONP脚本。来源前缀转换不照搬原软件错误。

2026-10-27新增东财日K截止日期（代码已实现，尚未部署）。指定日期仍固定`fqt=1`，
上游`end=yyyyMMdd`，响应回显`trade_date`及`upstream_parameters`；返回日期晚于截止日报502。
空数组及不足请求条数如实返回，不向前补造数据；未收盘日的末根仍可能是实时价格。
日期参数只截断K线，不固定历史复权基准：前复权价格由来源查询时决定，可能随后续除权修订，
不能用它冒充历史时点快照。年线计算、250根完整性及价格基准核对属于消费系统职责。

## 上游地址、实际参数和返回映射

以下来源地址来自软件源码及少量只读核查，不是服务方正式开放API协议。
固定ut/randomCode来自源码，不代表个人凭证或永久授权；消费者API Key不转发上游。
查询串由urlencode生成，表达式中的+编码%2B、冒号%3A。时间戳例1791855900000实际替换为当前毫秒。
响应upstream_parameters回显真实查询参数或完整POST体。

### 1. 东方财富行情

上游GET：`https://push2dycalc.eastmoney.com/api/qt/clist/get`

```text
fs=m:1+t:2,m:0+t:6,m:1+t:23,m:0+t:80
fltt=2; invt=2; fid=f3; po=1; np=1; pn=1; pz=5000
fields=f2,f3,f4,f5,f6,f8,f10,f12,f14,f17,f18,f20,f21,f26,f615,f630,f100,f102,f103
ut=c92c50e6b0fab2c17cd5e276e9a79c42
_=1791855900000
```

pn/pz=公共page/page_size；mainboard fs=m:1+t:2,m:0+t:6，star=m:1+t:23，growth=m:0+t:80。
要求整数rc=0及data.diff数组；data.total→total，不自动补全市场。
f12/f14→code/name，f2/f3→last_price/change_pct，f17/f18→open/previous_close，
f5手×100→volume_shares，f6元→amount_cny，f8/f10→turnover_rate_pct/volume_ratio，
f20/f21元→总/流通市值，f26→listing_date，f100/f103→industry/concepts。
f615/f630/f102尚未核实语义，不公开为标准事实。

### 2～4. 东方财富涨停/跌停/炸板池

| 池 | 上游GET地址 | sort |
|---|---|---|
| 涨停 | `https://push2ex.eastmoney.com/getTopicZTPool` | fbt:asc |
| 跌停 | `https://push2ex.eastmoney.com/getTopicDTPool` | fund:asc |
| 炸板 | `https://push2ex.eastmoney.com/getTopicZBPool` | fbt:asc |

共同参数ut=7eea3edcaed734bea9cbfc24409ed989、dpt=wz.ztzt、Pageindex=page-1（例0）、
Pagesize=page_size（例500）、date=trade_date去横线（例20261012）、_=当前毫秒。
要求rc=0、data.pool数组、data.qdate等于请求日。tc→total、c/n→证券标识，
涨停lbc→consecutive_limit_up_days、fbt→first_limit_time(HH:mm:ss)、zbc→break_count、
fund元→sealing_amount_cny、hybk→industry；跌停池首次封板/炸板数为空。
2026-10-13抽查中历史date可能返回其他qdate；服务明确502，不回退当前池或伪装空池。
不计算情绪等级、最高板或炸板率，不自行移动交易日。

### 5. 东方财富前复权日K

上游GET：`https://push2his.eastmoney.com/api/qt/stock/kline/get`

```text
secid=1.600000
fields1=f1,f2,f3,f4,f5,f6
fields2=f51,f52,f53,f54,f55,f56,f57,f58,f59,f60,f61
klt=101; fqt=1; end=20500101; lmt=160
```

SSE取1.code、SZSE取0.code，lmt来自limit。data.klines前七列为日期/开/收/高/低/量/额；
量手×100、额直接读元，adjustment=forward。UT与软件部分请求变体不同，固定参数完整回显。

### 6. 腾讯日/周K

server=web时上游GET：`https://web.ifzq.gtimg.cn/appstock/app/fqkline/get`；
server=ifzq时：`https://ifzq.gtimg.cn/appstock/app/fqkline/get`。
参数例`param=sh600000,day,,,640,qfq`或`sz000001,day,,,120,qfq`；
symbol转sh/sz，period为day/week，limit为数量，两处日期空。
读取qfqday/qfqweek；仅返回day/week时adjustment=none，不能伪称前复权。
数组0～5为日期/开/收/高/低/手数；手×100，成交额null，不按收盘×量推算。
最多返回末limit条，末条可能未完成；不伪造当日K线，不自动切换服务器、不执行JSONP。

### 7. 新浪日K

上游GET：`https://money.finance.sina.com.cn/quotes_service/api/json_v2.php/CN_MarketData.getKLineData`。
参数例symbol=sz000001、scale=240、ma=no、datalen=120；symbol转sh/sz、datalen来自limit。
根数组day/open/close/high/low/volume→标准日K；volume按股，不乘100。
amount_cny=null，adjustment=unspecified；复权未明确，不与其他来源默默合并成同复权行情。

### 8. 腾讯分时图

上游GET：`https://web.ifzq.gtimg.cn/appstock/app/minute/query?code=sh600000`；深圳例sz000001。
要求整数code=0，读取data[tcode].data.date及data[tcode].data.data。
人工构造行示意：

```text
0930 10.00 10 10000
0931 10.50 30 31000
```

位置0 HHmm→time（09:30）；1价格元→price；2累计手数×100→cumulative_volume_shares；
3累计元→cumulative_amount_cny，缺失null。第二行累计3000股/31000元，
不能再累加为4000股/41000元；不复用原软件重复累计均价算法。
没有竞价时段就不补点；来源date明确回显trade_date，休市可能是上一来源日。
时间有效递增，累计量额非负不倒退；异常502，不生成均价或策略标签。

### 9. 腾讯上证指数

上游GET：`https://qt.gtimg.cn/?q=sh000001`；无公共参数，固定上证指数。
GBK文本v_sh000001按~切分：1名称、3当前点位、4前收点位、32涨跌幅。
原软件误读33最高点位作涨幅，接入已纠正；不生成指数策略。

```json

  "args": {"pageSize": 100, "pageNum": 1, "sort": -1},

  "randomCode": "QMvrYSV2BSS4uDmf", "timestamp": 1791855900000
```

成员的请求体例：

```json
{
  "args": {"themeCode": "00647", "pageSize": 1000, "pageNum": 1, "sort": -1, "sortField": "f3"},

  "randomCode": "QMvrYSV2BSS4uDmf", "timestamp": 1791855900000
```

## 响应、错误与运行配置

响应含source_code/source_name/source_website、upstream_url（不含查询串）、upstream_method、
upstream_parameters、purpose、persisted=false、observed_at、page/page_size、trade_date、
symbol、adjustment、total、items。完整字段说明见Swagger与contracts/fastapi-openapi-v1.json。
observed_at为收到响应的上海YYYY-MM-DD HH:mm:ss，不是来源成交时间；日期字段YYYY-MM-DD。
Decimal价格/数量/金额/比例为十进制字符串，缺失null、真实零"0"。
page_size是请求上限，分时/指数为实际数量、K线为limit；实际返回量为items.length。

| HTTP | 含义 |
|---|---|
| 401 | 原有API Key鉴权失败，不访问上游 |
| 422 validation_error | 非法参数/未来池日期/不支持代码或服务器，不访问上游 |
| 502 upstream_error | HTTP/网络/业务失败、超限、布局异常、日期/代码不符、非法值；不泄露异常文本 |
| 200 | 明确成功结果，包括真实空数组 |

固定来源白名单、禁止重定向和系统代理、正文上限8MB。
FASTAPI_AUCTION_SOURCES_TIMEOUT_SECONDS默认8，可设1～10；属于urllib/socket超时，
不是总墙钟截止时间，缓慢分块读取可能更久。来源限频/数据过期/布局变化不伪装成功。
2026-10-13已完成本版本的生产API发布，详情见[生产发布记录](runbooks/auction-sources-production-2026-10-13.md)。
后续版本仍须按现有apiServer发布流程上线，不能用本次记录替代新的验收。

测试fixture为人工构造，不提交线上Raw。验收覆盖12路由、鉴权、边界、单次请求、
零/null、单位、累计分时、复权、日期、OHLC、重复键和契约一致性。
小范围线上只读抽查不构成长期可用性保证。

# ADR-0073：Raw 月前永久清除，不再归档

- 状态：Accepted
- 日期：2026-10-24
- 关联：Issue #96、ADR-0069、ADR-0070、ADR-0072
- 授权依据：所有者要求「raw文件最多保存1一个月，一个月前的raw定时清除」，并明确回答「旧 Raw 不再归档」。

本决定替代ADR-0072的归档批准队列方案，取消过期Raw离线归档前置条件；不删除既有独立备份，
不改变业务结果归档期限、单位规则或标准数据。不得再为本次旧Raw清除请求归档位置确认。

每日03:00原Worker清理任务增加`purge_expired_raw`。截止日为上海执行日减一个自然月，严格早于
截止日零点；月末截取到上月最后一天。已登记Raw的Manifest创建和采集终态完成均须超过该期限。
Worker根与API独立根分别显式配置，API根通过`RAW_RETENTION_API_ROOT`，不根据缺失文件猜根。

Raw数量、价格、单位及内容不改写。过期原件和gzip表示在精确内容/文件身份校验后永久删除，
不创建新归档。JSONL核对SHA、字节、行数；Parquet核对原始字节SHA，保留原Manifest全部信息。
`ingestion.raw_purge`是永久清除事实，不能填充虚假archive_ref或伪造离线备份证据。
先在独立事务声明清除，再移除并fsync目录，最后确认。中断后只允许已有精确声明接受文件缺失。
原本已缺失且未声明的对象单独报错，不冒称本次删除。重复执行不会重复删除或累计释放字节。

标准事实、基础资料、快照和采集/计算/单位认证血缘保留；它们不再要求月前Raw文件在线。
运行中的回放临时保护Raw，完成后下次处理。声明和新回放INSERT通过同一逐Raw锁串行，
正常及预览回放在读文件/创建新Run之前报告「按月度保留策略永久清除」，不谎称存在离线归档。
超期Raw不再保证可重放或可恢复。历史归档恢复须先在逐Raw事务锁下调用
`ingestion.assert_raw_restorable`，已永久清除的UUID禁止用旧流程重新发布文件。

未登记Raw仅处理已知Provider命名空间内的标准UUID文件路径（JSONL/Parquet及gzip），按
mtime和ctime中较新的时点判断在线年龄，不能从分区业务日期推断采集年龄。仍有Manifest或
运行采集者保留；近期、未知格式、软链接、junction和非Raw归档不盲删。
`ingestion.raw_orphan_purge`记录实际物理哈希、字节、时间及路径；声明和迟到Manifest登记
通过同一逻辑路径锁串行，防止删后才被注册成成功来源。失败保留并报告，默认预览无写入。

每页200、合计最多10000对象、最多5分钟，共享原30分钟预算及维护锁；首次积压可按同一
固定边界有界续跑，不能因任务已启用就声称全部处理完。压缩须排除永久清除声明，防止重建旧文件。
清除审计、Manifest和两类历史归档登记纳入数据库恢复元数据；不因此执行常规数据库备份。
生产只能通过有序迁移和受保护流程授权函数，Worker没有审计表任意UPDATE/DELETE权限。

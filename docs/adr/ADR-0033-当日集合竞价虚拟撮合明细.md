# ADR-0033：当日集合竞价虚拟撮合明细

- 状态：Accepted
- 日期：2026-08-14
- 关联 Issue：#47
- 扩展：ADR-0011、ADR-0022、ADR-0028

## 决策

建立独立的 `call_auction_indicative_detail` 来源事实，首个适配器为东方财富普通 JSON
`stock/details/get`。它只接受单只 SSE/SZSE 股票和 Asia/Shanghai 当前交易日，仅保留
09:15:00–09:25:59。数据语义固定为“开盘集合竞价虚拟参考/匹配明细”，不是交易所逐笔成交、
不是逐笔委托，也不是完整订单簿。页面内外盘代码只映射为不可信的来源展示分类；不得用相邻价格
推断方向。

每次请求最多 5000 个来源行，达到上限即按可能截断失败；连接/读取总超时 1–15 秒，最多两次
尝试、单进程串行。仅提供需要显式确认的单证券 CLI，不注册 APScheduler、cron 或全市场任务。
HTTP/JSON/字段异常、反爬响应和空有效窗口都必须可见，不伪装成完整结果。

Raw JSONL 保存原始五字段及来源顺序，Manifest 保存摘要、大小、行数和 schema version。每次
ingestion 形成 append-only version；Raw、Manifest、quality、snapshot、detail 在一个 PostgreSQL
事务登记。保留期首版不自动删除；调整前需另行治理决策。

FastAPI 新增 `/api/v1/call-auction-indicative-details`，必须 API key，调用有界 `api_v1` RPC。
RPC 只授权 `market_data_api`，拒绝非当日日期、历史回退、BSE、越界分页和内部表直接读取。

## 来源与许可

公开页面可访问不代表允许自动化采集、长期保存或再分发。东方财富接口没有公开 SLA、稳定字段
契约或限频承诺；上交所交易信息权利和东方财富条款必须在生产启用前由使用方完成审阅并取得所需
许可。未通过该门禁时 CLI 保持禁用，不得计划化或规模化采集。

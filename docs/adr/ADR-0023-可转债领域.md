# ADR-0023：可转债领域

- 状态：Accepted
- 日期：2026-08-07
- 关联 Issue：#36
- 决策者：项目所有者
- 影响：新增 `convertible_bond` schema、Tushare `cb_*` 适配、调度、只读契约
- 详设：[领域详设-ConvertibleBond-2026-08-07.md](../领域详设-ConvertibleBond-2026-08-07.md)

## 决策

1. 新增 `convertible_bond` 独立 schema，保存四类客观事实：基础条款、每日行情、转股价
   调整历史、赎回/回售事件。价格、比例、金额使用 Decimal，单位为 CNY；缺失与零严格
   区分。`volume` 保持来源的"张"语义，不换算为"股"。
2. 可转债复用 `core.security`（`security_type='convertible_bond'`，枚举已预留），
   `list_date`/`delist_date` 映射为 `ipo_date`/`delisting_date`。正股通过
   `underlying_symbol` 外键指向另一条 `security_type='stock'` 的记录。
3. 可转债每日行情**不复用 `core.daily_bar`**。可转债行情携带转股价值、转股溢价率、
   剩余规模等债券专属字段，`volume` 单位是"张"而非"股"，且无 `is_st` 概念。独立
   `convertible_bond.daily_bar` 表保护既有股票日 K 契约不被污染。
4. 主来源为 Tushare（`cb_basic`/`cb_issue`/`cb_daily`/`cb_share`，2000 积分已确认可
   访问）。pytdx 本地 `.day` 文件作为 OHLCV 备选（路径已兼容，但只产出量价、无债券
   专属字段，且 `trade_status=unknown`），不进入自动路由。AKShare 作为补充与交叉校验
   源。来源字段名与单位在 Provider adapter 边界内转换完成，不泄漏到领域 Record。
5. 基础条款与每日行情采用覆盖语义（`on conflict do update`，最新批次为准）；转股价
   调整与赎回/回售事件采用事件流语义（按自然键保留历史）。`source_code`/`ingestion_id`
   不参与自然键。
6. 转股导致的正股股本变动由 `capital.share_capital` 权威记录
   （`change_reason='convertible_bond_conversion'`），本领域不重复维护正股股本数字，
   只记录"本债转了多少股"。
7. 纯债价值、到期收益率（YTM）若需自主计算（贴现现金流），进 `derived` schema 版本
   化，不污染 core 事实表；首版 `daily_bar` 的 `bond_value`/`ytm` 允许为空，存来源
   发布值。
8. 新增 DatasetCode `convertible_bond`、`convertible_bond_daily_bar`，扩展
   `ingestion_run`/`quality_result` 的 check 约束。新增受控 WorkflowDefinition 和
   JobDefinition（可配 `CONVERTIBLE_BOND_HOUR`/`_MINUTE`，建议紧随 daily-run），
   纳入 operations 记录、陈旧恢复和本地只读任务页面。
9. `api_v1` 提供 `convertible_bonds`、`convertible_bond_daily_bars` 只读视图和有界
   RPC `query_convertible_bond_daily_bars`（5 秒超时，≤5000 行）。视图剥离
   `source_code`/`ingestion_id`，不暴露内部字段。
10. 公募可交债（`118xxx`/`117xxx`）业务不同，首版不纳入；未来如需接入应单列
    `security_type='exchangeable_bond'` 并另建 ADR。

## 限制

- Tushare `cb_rate`（逐年级票面利率）需 5000 积分，首版 `coupon_rate` 只存 `cb_basic`
  的代表性利率，`coupon_schedule` 留空待 5000 积分填充。
- Tushare `cb_daily.vol` 的单位（手 vs 张）需在 adapter 实施时核实确认；若为"手"需
  ×10 换算为"张"。本文档不预设该换算。
- 强赎/回售事件 Tushare 无独立规范接口，首版从 `cb_issue` 条款文本和 AKShare
  `bond_cb_redeem_js` 解析，完整性依赖来源公告质量。
- 首版不实现可转债 Security 目录的自动采集路由——`cb_basic` 同时承担目录与条款双
  重角色，需在 Provider 适配时明确 Security 与 ConvertibleBond 的事实分工。
- pytdx 路径虽兼容可转债代码，但通达信客户端默认不下载债券日线；pytdx 备选仅在
  本地有 `.day` 文件时可用。

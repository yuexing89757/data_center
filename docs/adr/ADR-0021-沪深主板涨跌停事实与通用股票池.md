# ADR-0021：沪深主板涨跌停事实与通用股票池

- 状态：Accepted
- 日期：2026-08-02
- 关联 Issue：#34

## 背景

后续 9:15–9:25 五档观察需要一个在开盘前已经冻结、可追溯且不会自动回退日期的证券集合。
`THS:883423` 和第三方涨跌停榜可以用于未来质量核验，但不能成为正式成员事实。Data Center
已经拥有证券主数据、交易日历、未复权日 K、每日指标、版本化计算批次和 Operations 记录，
可以确定性地计算客观涨跌停事实。

## 权威规则依据

首版只接受 2026-07-06 起生效的沪深交易规则：

- [上海证券交易所交易规则（2026年修订）](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)
  自 2026-07-06 生效；上交所说明主板风险警示股票涨跌幅比例由 5% 调整为 10%。
- [深圳证券交易所交易规则（2026年修订）](https://docs.static.szse.cn/www/lawrules/rule/trade/current/W020260424690713155663.pdf)
  第 3.3.11、3.3.13–3.3.19 条明确主板 10%、A 股最小价格变动单位 0.01 元、以前收盘价
  计算上下限、四舍五入至最小价格单位，以及 IPO 前五个交易日、重新上市首日、退市整理首日
  等无涨跌幅限制情形。
- [深交所主板与中小板合并安排](https://www.szse.cn/disclosure/notice/general/t20210331_585343.html)
  确认主板 A 股代码区间为 000001–004999；001001–001199 的主板存托凭证由
  `security_type=stock` 和代码子区间双重排除。
- [上交所主板代码范围](https://www.sse.com.cn/star/en/marketdata/overview/)及 605 号段规则用于
  识别 600000–603999、605000–605999；688/689 明确不属于主板股票。

## 决策

1. 建立通用 `StockPoolDefinition`、不可变 `StockPoolSnapshot` 和 `StockPoolMember`；首批代码为
   `CN_A_PREVIOUS_DAY_MAINBOARD_LIMIT_UP` 与
   `CN_A_PREVIOUS_DAY_MAINBOARD_LIMIT_DOWN`，两者共享全部基础设施。
2. 建立 `DailyPriceLimit` 与带 `direction=up/down` 的 `PriceLimitEvent`。价格使用 `Decimal`；
   `PriceLimitRule` 按交易所、板块、ST 适用比例、上市阶段和生效区间版本化。首版规则版本
   `CN_MAINBOARD_2026_07_06` 对沪深主板普通及风险警示股票均为 10%，价格档位为 0.01 元，
   算法版本为 `1.0.0`。
3. 涨跌停价按 `前收盘价 × (1 ± 比例)` 计算并使用 `ROUND_HALF_UP` 取至档位；若差额小于一个
   档位则至少增减一个档位，下限最低为一个档位。收盘价必须精确等于对应上下限才形成事件。
4. `basis_trade_date` 是事件发生日，`effective_trade_date` 必须来自日历的下一交易日。RPC 只按
   `pool_code + effective_trade_date (+ version)` 精确读取；找不到 ready 快照抛出 `P0002`，
   禁止回退旧日期。
5. 快照保存独立 version、member/candidate/rejected count、content/input SHA-256、
   calculation ID、规则/算法版本和生成时间。相同输入幂等复用；输入修订生成新 calculation 和
   新 snapshot version，不更新旧快照。
6. 计算前必须存在 basis 当日成功的 `daily_market` 与 `stock_daily_indicator` WorkflowRun，
   且逐证券具有日 K、每日指标 lineage、正前收盘价、交易状态以及连续五个此前交易日的交易
   日 K。连续性门禁保守排除无法证明不是重新上市、退市整理或其他无涨跌幅限制阶段的证券。
7. 创业板、科创板、北交所、非股票、上市前五日、缺失或矛盾输入均不纳入，并留下计算质量
   结果。OHLC 超出所选上下限时视为规则不适用或数据异常，拒绝该证券，不从第三方榜单纠正。
8. 自由流通换手率、自由流通股本和流通市值继续来自 `core.stock_daily_indicator`，RPC 在读取
   时组合，不复制到成员。`PriceLimitSealSummary` 只定义未来盘口来源边界；本期没有盘口事实，
   不建造零值或伪造封板金额。
9. 每个交易日 19:30（Asia/Shanghai）运行一个共享的涨跌停股票池任务，晚于 19:00 每日指标；
   时间只决定尝试，依赖检查决定是否可构建。失败进入 Operations，不回退旧快照。
10. 本期不启动五档持续采集，THS/Tushare 榜单不参与正式计算。

## 限制

- 2026-07-06 之前存在 5% 风险警示、旧 IPO 首日和其他历史规则，首版明确不支持；请求旧日期
  必须失败，不能套用现行 10% 规则。
- 当前主数据没有交易所发布的逐日“重新上市/退市整理首日”字段，因此采用此前五个交易日连续
  日 K 的保守门禁；这会宁可排除部分复牌股票，也不会猜测其涨跌停规则。
- 每日指标 Core 只保留近一个月，历史股票池重算必须在输入仍可用或建立另一个 Accepted ADR
  后进行，不能从当前快照反推。

## 2026-08-10 Accepted clarification：FastAPI 精确日期涨停池

- `GET /api/v1/limit-up-pool?trade_date=...` 中的 `trade_date` 是涨停事件发生的
  `basis_trade_date`，不是次一交易日的 `effective_trade_date`。查询只选择该日期的 ready
  主板涨停快照；可指定 version，未指定时选择该日期的最新版本，绝不回退其他日期。
- “涨停”仍严格表示未复权日 K 收盘价按 `Decimal` 精确等于 ADR 本文规则计算的涨停价。
- `free_float_market_cap_cny` 唯一定义为同一 `trade_date` 的未复权
  `core.daily_bar.close × core.stock_daily_indicator.free_float_shares`。价格单位为元/股，股本
  单位为股，结果单位为元；数据库 numeric 运算和 API Decimal 字符串保持精度，不使用
  `circulating_market_value`、其他市值字段、float 或外部榜单替代。
- 名称按 `security_name_history` 在 `trade_date` 的有效区间读取，不使用当前名称改写历史。
  缺少当日日 K 事件、自由流通股本或历史名称的成员逐行省略，不影响其他有效成员，也不返回
  空值、零值或替代值。响应公开总候选数、有效数、返回数、唯一省略数及按
  `missing_name`/`missing_close`/`missing_free_float_shares` 分组的非敏感计数；一行可命中多个原因，
  所以分组计数之和可大于唯一省略数。
- `limit` 在完成全快照质量分类后仅作用于有效成员，顺序固定为标准 symbol 升序；
  `has_more` 表示仍有有效成员未返回。首版没有 offset/cursor，调用方需要完整集合时使用上限
  5000，而不能把重复增加 limit 当作游标分页。
- 响应携带 snapshot/calculation ID、input hash、规则/算法版本、生成时间及 effective date。
  上游事实修订只能产生新的 calculation 和 snapshot version；历史版本保持可重现。

# ADR-0029：同日涨停不可变快照与 22:00 填充任务

- 状态：Accepted
- 日期：2026-08-11
- 跟踪：GitHub Issue #43

## 决策

新建 `today_limit_up` 边界，不复用 `stock_pool.member`，也不改写现有
`/api/v1/limit-up-pool` 或 `/api/v1/daily-limit-up-list`。首版仅覆盖已有版本化涨停规则
支持的 SSE/SZSE 主板；创业板、科创板和 BSE 待各自规则被治理后扩展。

数据分两层：

1. `source_observation` 追加保存 AKShare/Eastmoney 当日涨停榜的来源观察、Raw 和
   ingestion lineage。来源名称、最新价、涨幅和来源流通市值不覆盖规范事实。
2. `snapshot`/`member` 保存版本化、不可变的规范快照。成员资格仅来自未复权日 K
   与版本化涨停价；历史名称、同日日 K、同日 `free_float_shares` 均为必要输入。

`free_float_market_cap_cny` 仅等于同日未复权 `close * free_float_shares`，使用 Decimal/
PostgreSQL numeric 计算。`source_reported_sealed_funds_cny` 是来源报告值，与
`closing_bid1_sealing_amount_cny = closing_bid1_price * closing_bid1_volume_shares`
永久分列，后者不是五档合计。只有同日收盘五档记录价量完整且 bid-1
精确等于涨停价时才计算；否则留 NULL 并记质量原因。

首次/末次封板时间是 `trade_date + HHMMSS` 的 Asia/Shanghai 时刻。由于开板后可再封，
不得用首末时间之差伪造累计封板时长；v1 的 `limit_up_duration_seconds` 为 NULL，
`duration_semantics='unavailable_without_event_stream'`。

Worker 在交易日 22:00 Asia/Shanghai 运行受控任务。任务不以墙钟代替依赖检查：
必须核对精确 `trade_date` 的日 K、指标/流通股数和 ready 主板涨停池。缺失或上游
failed/partial 必须产生可见 `deferred` 或 `partial` 状态及原因。相同输入哈希重试返回
既有版本；任一上游修订产生新版本，不 update 历史快照。

## 限制

- `stock_zt_pool_em` 是当日来源，无历史 SLA；Raw 必须保留，空池与请求失败必须区分。
- 该来源不提供五档。BSE 的 pytdx 五档能力未验证，不得伪造。
- 现有 `realtime.eod_quote_snapshot` 是可变投影；新成员只冻结构建时的值及
  ingestion lineage。在 Raw 重放证据完善前，这是已记录的可重现性限制。
- 新领域首版不新增公开 API；实际数据验证后另行以有界 RPC 增量发布。

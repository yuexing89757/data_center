# ADR-0037：沪深股票收盘价严格突破近 120 交易日新高只读契约

- 状态：Accepted
- 日期：2026-08-16

## 决策

新增无参数 `GET /api/v1/close-price-new-highs-120d`，由独立 FastAPI 进程调用无参数、有界的
`api_v1.query_close_price_new_highs_120d()`。RPC 自动选择数据库中沪深普通股票存在有效正收盘价的
最新 `CN_A_SHARE` 交易日，不接受调用方日期，也不回退到其他证券市场。

每只候选股票必须在截至所选日期的连续 120 个市场交易日中都有正收盘价，且状态为
`trading` 或 pytdx 无法判定时的 `unknown`。明确 `suspended`、任一日缺失或非正收盘、缺当日
历史名称的股票不参与判断。当日未复权收盘价必须严格大于此前 119 个交易日的最高未复权收盘价；
相等不算突破。结果仅包含 SSE、SZSE 的 `stock`，不包含 BSE，并按突破百分比降序、symbol 升序
稳定排序。

接口不分页并返回全部符合项，但候选全集硬限制为 10,000 只，RPC 保持 10 秒语句超时；超过边界直接
失败，不截断结果。响应包含所选交易日、120/119 会话语义、候选/有效历史/遗漏/返回数量、分组遗漏
计数，以及每只股票的 code、symbol、当日名称、收盘价、此前 119 日最高收盘价和突破百分比。
RPC 仅授权 `market_data_api`，不写表、不触发采集，也不从网络补数据。

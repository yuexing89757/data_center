# ADR-0031：近 20 交易日涨幅 Top 10 只读契约

- 状态：Accepted
- 日期：2026-08-14
- 跟踪：GitHub Issue #45

## 决策

新增 `GET /api/v1/top-gainers-20d`。20 个交易日由 `CN_A_SHARE` 日历确定，包含起止两个观察日，因此收益区间数为 19；`return_pct=(end_close/start_close-1)*100`，仅使用未复权 `core.daily_bar.close`。显式日期必须是交易日且不回退；省略时选择同时存在可交易正收盘价的最新交易日。缺精确起止日 K 线、非 trading、非正价格、缺当日历史名称或不足 20 个日历观察的证券不参与排名，并返回分组遗漏计数。排序为收益降序、symbol 升序，limit 范围 1..10，默认 10。RPC 仅授予 `market_data_api`。

# ADR-0057：股东人数非法行隔离

- 状态：Accepted
- 日期：2026-09-22
- 决策者：项目所有者（本次修复中明确确认）
- 替代：ADR-0047 第4、5项中可定位到单条标准记录的错误阻断全部合法事实的行为
- 范围：现有 ShareholderCount 校验、采集、Raw 重放；无新表或公共接口

## 背景

来源中一条公告日提前统计截止日3天的记录，阻断了同次请求所有合法事实。日期不变量仍然
有效，不能修改来源日期或将非法记录作为警告后写入 Core。

## 决策

1. 已标准化记录逐行校验。未知证券、日期冲突、非正人数、来源/修订键错误及批内重复记录
   均禁止入库，保留不可变 Raw，登记 ERROR/FAILED 质量记录和自然键；重复键的全部行拒绝，
   不选第一条或最后一条。
2. 合法记录通过现有一次事务发布；有拒绝且有合法记录为 partial，全拒绝为 failed。
   网络、结构解析、数据库错误仍阻断本次同步，不发布不完整请求集合。
3. 公告日早于统计截止日1至2个自然日继续允许，3日及以上继续拒绝，不改数据库硬约束。
4. 实时采集和 Raw 重放使用相同校验与质量记录逻辑。跨切片自然键冲突继续由发布层拒绝，
   不合并冲突事实。可能截断的探测请求仍递归拆分，不将探测请求作为完整事实发布。
5. 复用现有质量、计数、Raw 血缘和数据库权限，无 schema migration 或公共契约变更。

## 验收

覆盖混合合法/非法记录、全拒绝、重复键全部拒绝、日期容差、Raw 重放和错误级别；旧有
数据库日期约束及来源错误整批回滚继续有效。

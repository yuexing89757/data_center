# ADR-0069：授权月度历史数据离线归档与线上清理

- 状态：Accepted（所有者直接授权的一次性运维范围；执行结果另行记录）
- 日期：2026-10-23
- 决策者：项目所有者
- 关联：Issue #84、ADR-0058、ADR-0068

所有者要求“现在删除1个月以前的所有数据”，优先保障集合竞价与程序流畅，随后明确选择
“旧 Raw 移到已验证的离线归档，线上删除”；近期依赖的基础资料和血缘保留。

本次业务日期边界为严格早于2026-09-23；时间戳按上海零点。只处理本项目已核实的对象，
不触及其他应用、配置、凭据或既有独立备份。此授权替代ADR-0058对本次过期历史明细的
禁止删除边界，不修改03:00任务既有保留策略，不允许为了容量放宽单位认证或改公式。

先输出逐表只读清单，再完整归档旧行并在独立介质校验，按静态业务谓词、主键和全行一致性
有界删除。禁止隐式级联、全表清空和混入截止日；每批事务、原始归档、SHA、执行回执及
可恢复记录保留。父项仍有引用时阻断，不以外键级联绕过未归档子项。

保留近期集合竞价事实、证券/交易日历等有效基础资料、采集/计算/修复血缘及近期计算需要的
历史窗口。日K保留截止日前120个交易日作为最大已知滚动窗口；有持续适用意义的财务、
股本、监管链等数据不能按创建时间机械删除。所有保护例外和未执行对象须逐项记录。

旧Raw仅在独立离线副本按逻辑SHA、字节、行数核验且无线上保留事实依赖后，删除精确匹配的
线上表示；Manifest内容与血缘不伪造、不就地改写。离线索引记录Raw标识、原逻辑哈希、
归档位置及恢复方式。读取已退役历史Raw需要显式恢复，不把文件缺失当作采集成功。

实施为管理员手工运维工具，不扩Worker写权限，不新增OS任务，不做临时DDL。
Raw线上移除前通过有序migration建立`ingestion.raw_retirement`，记录精确Raw身份、独立归档索引
摘要和移除/恢复确认；Worker仅有SELECT，管理员控制退役和恢复。定时压缩排除未恢复的退役项，
显式回放和来源比较在创建新Run或读文件之前报告“archived offline”，避免把计划内离线当缺失反复重试。
原Manifest、逻辑哈希及数量认证保持不变，备份/恢复清单包含退役登记。
此登记是所有者离线归档要求的必要实施边界；不将本次一次性范围自动推广为永久全域保留策略。
数据库删除先回收可复用页面；不以VACUUM FULL阻塞近期服务，不声称逻辑删除必然释放OS空间。

验收包括完整归档验证、日期边界、全行漂移拒绝、原始数值精度、幂等/中断恢复、父子引用、
分区数据、实例绑定及归档替换防护，最后复核近期竞价数据和Worker/API实际状态。

补充：Raw首次退役必须先验证真实在线表示，计划绑定Raw根的规范路径摘要和设备/inode；
只有同证据未恢复的既有登记可在表示缺失时继续完成。回放INSERT在数据库以逐Raw事务锁
与管理员登记串行，避免先读资格、后插入回放造成竞态。旧竞价轮次清理的外键检查使用
20261023000700新增的(session_id,sample_seq)索引；不绕过约束或延长为无限超时。
保留股票池快照时一并保留其基础日价格事件/限价/指标；仍有会话引用的旧池及子事实均保留。

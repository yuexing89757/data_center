# ADR-0034：龙虎榜不可变事实与席位活动

- 状态：Accepted
- 日期：2026-08-18
- 跟踪：GitHub Issue #57

## 决策

新增独立 `dragon_tiger` 领域，保存来源可追溯、按交易日版本化且不可变的龙虎榜事实。
它不复用 `stock_pool`、`today_limit_up`，也不把涨停、策略或主观“游资”判断写成龙虎榜事实。

一次来源获取形成一个 `(trade_date, version)` 的 `source_snapshot`，Raw、Manifest、
Ingestion、Quality 和规范事实在单一 PostgreSQL 事务登记。相同 `input_hash` 复用既有版本；
来源内容变化新增版本，不更新旧事件。来源失败或字段不完整不得伪装为完整快照；可保存
`partial`，但必须带明确原因和质量记录。

规范层包括：

1. `event`：一证券一交易日事件，冻结当日历史名称、市场、未复权收盘、涨跌幅、成交额/
   换手率、事件状态与来源观察 lineage。
2. `reason`：规范原因代码/名称与来源原文永久分列；来源数值必须同时保留单位。
3. `seat`：仅保存稳定身份、机构/营业部等客观类型、券商/分支/地区、有效期、来源名称和
   归一化状态。身份修订新增有效期记录，不覆盖旧记录。
4. `seat_activity`：准确保存买/卖/双边、买卖净额、排名、来源席位名/顺序及 Raw lineage。
5. `event_summary`：只保存从当前事件的已存席位活动可重算的总额、机构总额，以及“按金额
   降序前五席位金额 ÷ 已存活动总额”的集中度。集中度不是全市场集中度，除非来源活动完整。

内部表全部启用 RLS。`market_data_worker` 仅有 `SELECT/INSERT`，无 UPDATE/DELETE；public、
anon、authenticated 与 FastAPI API 角色均无权限。本 ADR 不新增公开 API、调度任务或采集器。

## 时间、金额与缺失语义

- `trade_date` 是 Asia/Shanghai 交易日；采集时间使用 `timestamptz`。
- 价格为 CNY/股、金额为 CNY、换手率和涨跌幅为百分点；Python 使用 `Decimal`，数据库使用
  `numeric`，不经过 float。
- `NULL` 与 0 永久区分。未知席位类型、缺席位、缺原因或来源截断必须显式保留为未知/
  partial/quality finding，不补造。
- `seat_label_assignment` 若未来获批，必须放在独立证据化、版本化边界；本领域不提供该表。

## 来源限制

Eastmoney 仅是未来首个适配器候选。公开网页可访问不代表允许规模化采集、长期保存或再分发；
采集前仍需完成条款、许可、限频和保留期审查。本 ADR 不授权任何实际来源请求。

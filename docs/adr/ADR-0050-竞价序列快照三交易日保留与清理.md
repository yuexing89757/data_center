# ADR-0050：竞价序列快照三交易日保留与清理

- 状态：Accepted
- 日期：2026-09-03
- 关联 Issue：#71
- 决策者：项目所有者
- 替代：ADR-0034 第 9 项中的“PostgreSQL 按月在线保留最近 12 个月”
- 扩展：ADR-0015、ADR-0017、ADR-0034、ADR-0040

## 背景

`realtime.call_auction_market_series_snapshot` 每个交易日保存约 16.7 万条沪深全市场竞价序列事实。
生产库截至 2026-09-03 已保存约 224 万条、占用约 1.12 GB。当前消费者只需要最近三个已完成
交易日的在线标准快照，不需要在 PostgreSQL 中继续保留 12 个月。

删除标准快照不能连带破坏采集审计。Session、Round、Raw、Manifest、IngestionRun 和质量结果仍需
证明历史上采集了什么、采集是否完整以及事实来自哪个 Provider。09:25:30 单点快照是独立数据集，
不属于本次清理范围。

## 决策

1. 新增 Worker 任务 `data-cleanup-daily`，显示名称为“数据清理任务”，每天上海时间 03:00 执行。
   任务通过 APScheduler Worker 任务目录注册，不使用 cron、systemd timer 或 Windows Task Scheduler。
2. 新增 workflow `data_cleanup`，首版只有步骤 `cleanup_call_auction_market_series_snapshots`。
3. 清理只删除 `realtime.call_auction_market_series_snapshot` 的过期行。不得删除
   `call_auction_market_series_session`、`call_auction_market_series_round`、Raw 文件、
   `ingestion.raw_manifest`、`ingestion.ingestion_run`、`audit.quality_result`、Operations 运行记录或
   `realtime.call_auction_market_snapshot`。
4. 保留窗口为最近三个已完成交易日。任务以执行时的上海本地日期为参考，只查询
   `core.trading_calendar` 中严格早于该日期的 `CN_A_SHARE` 开市日，按日期倒序取三日，并以其中最早
   日期作为截止日。删除 `trade_date < cutoff_date`，截止日当天保留。
5. 如果交易日历不能提供三个符合条件的开市日，任务 fail closed，不执行 DELETE，并以失败状态记录
   明确错误。周末和法定节假日仍运行相同算法，不按自然日缩短保留窗口。
6. 删除在单个受控数据库事务中执行，返回精确删除行数并写入 JobExecution/WorkflowRun 统计。重复执行
   必须幂等；没有过期行时成功返回零。
7. `DATA_CLEANUP_ENABLED` 是唯一环境开关，默认启用。03:00、时区、三个交易日和目标表固定在代码目录，
   不提供环境时间、保留天数或目标表配置。
8. ordered migration 只授予 `market_data_worker` 对目标父表完成本任务所需的 DELETE 权限和受限 RLS
   policy，并扩展受控 workflow code。匿名、authenticated、API 角色和其他表不获得删除权限。
9. 保持现有月度分区结构。Worker 只执行 DML，不创建、分离或删除分区，不主动运行 VACUUM。空间回收
   交给 PostgreSQL autovacuum 和受保护数据库运维。
10. 对已清理交易日的竞价序列 API 查询继续返回保留的 Session/Round 元数据；各轮 Snapshot
   `items` 为空、`returned_count` 为零，请求代码进入 `missing_codes`。公共请求、响应和 OpenAPI
   合同不变。

## 后果

- PostgreSQL 竞价序列标准事实最多在每日清理完成后保留三个已完成交易日；当天早盘采集完成到下一次
  03:00 清理前，短暂存在当天加前三个已完成交易日的数据。
- 历史标准快照不再在线可查，但采集会话、轮次、Raw 和审计血缘继续长期保留。
- 首次运行可能删除大量既有历史行；此后每日通常只删除一个交易日，任务固定在非交易时段执行。
- 月度分区文件是否立即缩小取决于 PostgreSQL vacuum 行为，本决策保证逻辑删除，不承诺同步归还操作
  系统磁盘空间。
- 未来清理其他数据集必须另行决定保留期和审计影响，不得扩展此任务的目标表配置。

## 验收

- 纯截止日逻辑覆盖普通交易周、周末、法定休市和交易日历不足三日；
- Persistence 集成测试覆盖截止日前删除、截止日保留、幂等、事务回滚、RLS 和角色权限；
- Scheduler 测试证明任务每天 03:00 Asia/Shanghai 执行、默认启用且环境只能启停；
- Operations 测试证明删除行数进入 JobExecution/WorkflowRun，失败不会伪报成功；
- 生产检查和本地只读任务页包含新任务；
- ADR、设计、Worker 调度文档和运行手册同步更新；
- Ruff、mypy、全量 pytest 和隔离 PostgreSQL integration tests 通过。

# ADR-0032：09:26 集合竞价一字涨跌停只读契约

- 状态：Accepted
- 日期：2026-08-14
- 跟踪：GitHub Issue #46

## 决策

新增 `GET /api/v1/call-auction-one-price-limits`。只选择 Asia/Shanghai 09:26:00（含）至 09:27:00（不含）的 `call_auction_market_snapshot` 成功批次；无成功批次时允许最新 partial，且响应显式返回状态。省略日期时选择最新符合条件的交易日，显式日期不回退。

只有 `last_price`、`previous_close`、`high_price`、`low_price` 完整、正数且 `last_price=high_price=low_price=upper_limit`（涨停）或全部等于 `lower_limit`（跌停）时才称为该 09:26 快照下的“一字板”。涨跌停价必须来自同日最新成功且单一 calculation 的 `derived.daily_price_limit`；不得使用后续日线。缺名称、价格限制或报价证据的行只计入遗漏。RPC 仅授予 `market_data_api`，返回 ingestion/calculation lineage。

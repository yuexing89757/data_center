# ADR-0072：Raw 自然月线上保留与定时退役

- 状态：Superseded by ADR-0073（所有者随后明确「旧 Raw 不再归档」；本方案未在生产启用）
- 日期：2026-10-24
- 关联：Issue #96、ADR-0069、ADR-0070

沿用 Worker 的 03:00 `data-cleanup-daily`，增加 `retire_archived_raw` 步骤，不新增 OS 定时任务。
截止日为上海执行日减一个自然月，月末截取到上月最后一天，严格小于截止日零点。
Manifest 创建与采集终态完成时间均须早于该时点；不根据文件名或 mtime 猜测日期。
线上保留目标不是销毁独立离线副本的授权，也不覆盖仍有保留事实依赖的 Raw。

复用管理员专属 `ingestion.raw_retirement` 作为封存批准队列。管理员核对独立归档逻辑 SHA、
字节、行数、数据库实例、存储根身份及现存引用后，登记原始内容和归档索引摘要。
新列 `approved_storage_sha256` 绑定规范路径摘要、设备和 inode 的完整身份摘要；旧登记不会自动成为可执行批准。
Worker 不获登记或任意 UPDATE 权限，只可通过固定 SECURITY DEFINER 函数锁定合格批准及确认移除。
执行前再次核对当前事实及已知 JSON 血缘引用，锁住相关表直到该对象处理完成，防止排队期间新增引用。
恢复在接触文件之前必须取得逐 Raw 事务 advisory lock 和登记行锁，持有到文件验证、发布和
`restored_at` 确认提交，禁止先放回文件再等待更新登记。恢复过的旧批准不能再次消费。

执行复用原有 `remove_retired_raw`，对明文/gzip 全量逻辑校验、文件身份复核、精确 unlink、目录
fsync，最后同事务确认。批准先于文件删除持久化，删除后确认失败可以续跑；不修改 Manifest 或 Raw 内容。
每页 200、最多 10000 个、最多 5 分钟，共享原 30 分钟预算与维护锁；Raw 压缩缩为最多 10 分钟，
质检最多 5 分钟，历史结果最多 10 分钟，为本步骤预留 5 分钟。窗口/锁/预算失败停止新工作。

默认预览只读，返回到期未批准与已批准待处理的分页下界；截断不能当作全库统计。
到期未归档、根不匹配、引用变化、损坏、权限或预算问题均保留并报告 partial，不能称已全量按月清完。
独立API根通过`RAW_RETENTION_API_ROOT`显式配置，按批准的完整根身份选择存储，不按对象路径猜根。
未配置的根保留并报告；未登记文件、非JSONL、质量/历史归档目录不按普通Raw到期冒认删除。
持续机外归档通道尚未配置；本次不虚构自动上传成功，不增加外部写凭据。
代码与迁移的存在不表示生产任务已启用；上线、实际队列和积压须另记运行证据。

# ADR-0059：开盘啦异动提醒实时只读接口

- 状态：Accepted
- 日期：2026-09-27
- 决策依据：项目所有者要求接入开盘啦异动提醒，使用现有 FastAPI 规范，归类实时接口且不存数据库。
- Issue：待关联；GitHub 查询因连接失败未取得任务，本次未创建远端 Issue。
- 范围：既有实时查询模式的增量接入，不新增持久化领域。

## 决策

1. 在现有 FastAPI 注册 `/api/v1/realtime/kaipanla/alerts` 下十个路由，覆盖十四种已验证只读请求。
   复用 X-API-Key、Pydantic、统一错误响应、上海时区时间、中文 OpenAPI，分类“实时接口”。
2. 作为 ADR-0011 只调用 RPC 边界的明确例外，沿用 ADR-0045 请求时直连方式。不读写数据库、
   不创建 IngestionRun、不保存 Raw、不添加 Worker 任务、不回退数据库快照。无需数据库迁移，
   不新增 PostgREST/Agent 契约。历史参数也按请求读取，不意味着可重放的持久事实。
3. 固定上游方法、域名和 action，一次公共请求最多一次上游请求，不重试、不自动翻页，不带
   登录凭据、不跟随重定向、不使用系统 HTTP 代理。网络操作超时默认八秒，可配一至十秒。
   响应最多 2 MB；分页 1–20 条、偏移 0–10000；现价最多 100 个代码；单列表最多 5000 行。
4. 适配证券代码、列表分组、日期、现价、涨跌幅、监控起止日期、问询函日期与链接。
   JSON 小数直接转 Decimal，对外序列化字符串。保留 null 与零值差异，不访问公告链接。
5. 对来源字段边界做**仅限这些 provider 命名路由**的窄例外：未全面确认的数组通过
   `source_values` 保留完整原行，`source_layout` 区分布局。这些列不是标准指标，禁止直接用于
   Regulation 计算或写入领域事实。来源提醒不等于交易所确认的异动事件。后续确认语义后再加
   有名字段，不能猜测下标。已验证字段仍应使用标准有名字段。
6. 分别返回请求日期、实际来源日期、日期匹配标志；无来源日期返回 null。旧版历史日期错位
   显式返回 false，不把闭市快照日期换成服务器自然日。
7. 上游错误、非 JSON、异常结构、非法证券代码或网络故障返回 502 `upstream_error`，不泄露
   原异常，不包装为成功空列表。参数错误 422，未授权 401。
8. 账户设置读写不属于数据查询，本次不接入。

## 验证与影响

测试使用合成样例和不可调用的数据库服务桩，核对方法、请求参数、精度、分页、鉴权与错误。
真实只读验证十四种请求，不保存响应到项目。OpenAPI 随代码导出。
接口受第三方可用性与布局变更影响；APP 6.3.20.0、apiv=w48 为本次证据版本。

## 2026-09-27 增补：竞价池实时查询

项目所有者随后要求将开盘啦竞价接入相同 FastAPI 规范，沿用以上无持久化的查询边界。
新增 `GET /api/v1/realtime/kaipanla/auction-pool`，支持日期、偏移、1–30 条页长、ST 过滤。
传日期读取历史接口，省略日期尝试当前 HTTP 接口；未来日期拒绝。每请求仅一次上游访问。
历史日期必须严格匹配，不使用旧日期兜底；股票池与全市场竞价及旧伯乐候选池明确区分。

竞价的已确认字段全部转换为有名字段：金额元、涨幅/换手率百分比、Decimal 序列化字符串。
竞价不采用上文 source_values 例外，不提供未确认数组列。保留零和缺失值，拒绝非法数值、
重复股票和占位行。总数未知为 null，满页给出可继续尝试的 next_offset，无自动全量分页。
复用既有 `FASTAPI_KAIPANLA_TIMEOUT_SECONDS`、API key、异常响应、中文 OpenAPI 和时间类型。

当前 HTTP 实测返回 `kaipanla.com` 占位内容，应返回 502；尚未接入 APP 当日 Socket 2103。
此增补只新增实时读取契约、模型、Provider 与测试，不新增持久化领域、迁移、Worker 任务，
不改变既有数据库竞价数据和其他公共接口。详见[竞价接口说明](../开盘啦竞价实时接口.md)。

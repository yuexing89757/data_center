# ADR-0076：股票含当日五日均量日快照

- 状态：Accepted（项目所有者于 2026-11-04 在本聊天确认方案并授权本地实现；不包含生产操作）。
- 日期：2026-11-04。
- 关联 Issue：[#103](https://github.com/yuexing89757/data_center/issues/103)；GitHub Issue 为唯一任务规划记录。
- 关联：ADR-0009、ADR-0017、ADR-0019、ADR-0024、ADR-0068、ADR-0071。

## 背景

项目所有者要求新增定时任务，维护每日股票五日均量表，并明确窗口包含当日。
现有专业版技术因子目录没有五日成交均量；`ma_5` 是价格均线。
该结果可以由已认证的股票日 K 股数确定性计算，属于独立客观派生结果。

## 决策

1. 对目标交易日 T，取 CN_A_SHARE 日历中包含 T 的最近五个市场交易日，
   五日均量为这五日成交股数之和除以 Decimal(5)，单位股，包含当日。
   不以最近五条可用行情替代固定日期窗口，不作成交量复权或单位补偿。
2. 范围为 SSE、SZSE、BSE 普通股票，按目标日上市/退市生命周期筛选。
   输入只通过 `audit.unit_safe_daily_bar` 的标准股数准入，遵守 stock-quantity.v1。
   缺日、缺量、未认证数量、停牌缺口、上市不足五个交易日保持不完整；
   每只候选股票仍保存一行，均量为 null，并记录覆盖数及原因。已认证真实零参与计算。
3. 新增结果表 `derived.stock_volume_average_5d` 和轻量发布表
   `derived.stock_volume_average_5d_snapshot`，复用 `derived.calculation_run`，
   计算族 `cn_a_stock_volume_average_5d`，不可变算法版本 `1.0.0`。
   同日市场结果属于一个 calculation_id；旧结果不覆盖，输入变化生成新批次，
   当前日期按发布 version 选择一个成功批次，不按股票混选版本，不回退其他交易日。
   输入从 A 变 B 后再回到 A 时复用 A 的计算结果，追加发布版本，
   不篡改 A 的计算时间或违反共享成功签名唯一约束。
   发布表独立保存当次认证证据、水位和证据哈希；数值相同但来源认证替换时
   仍追加发布版本保存新证据，不静默复用已撤销的旧证据。
4. 纯 Calculator 接收无血缘 ID 的 DTO，仅做校验和 Decimal 计算。
   Service/Persistence 负责日期锁、Repeatable Read 输入快照、哈希、
   来源血缘与输入证据、批次幂等及事务内原子发布。
5. Worker 受控任务 `stock-volume-average-5d-daily` 建议在上海时间
   周一至周五 21:45 执行，默认启用，仅允许配置启停；先验证当日日历，
   休市成功跳过，日历未知或同日 daily_market 未处于 succeeded/partial 终态时失败。
   部分股票输入不完整发布 null 和质量原因，并在 Operations 中显示 partial。
   不新增操作系统级采集任务或网络补数，不增加自动历史回填。
6. 提供显式交易日重算入口供获准维护；首期只增加派生存储和 Worker 计算能力，
   不增加 FastAPI/PostgREST 读契约。未来消费者读取仍须通过单独批准的 api_v1 有界契约，
   不允许依赖 derived 底表。
7. 表、约束、索引、RLS、Worker 最小权限及 Operations workflow 白名单通过
   有序 migration 声明，并以单元测试与隔离 PostgreSQL 集成测试验证。

## 接受范围

用户于本聊天确认本方案，接受固定五个市场交易日、完整窗口才出数、
三交易所普通股票范围、21:45 时刻、表名以及首期不新增公共接口。

## 后果

日 K 单位未认证或缺失时会保留可见空值，不能承诺全市场都有数。
21:45 为计划时刻，不承诺日 K 已完成；失败后只能按精确日期显式重算。
历史版本和输入证据增加存储，本期不自动删除，也不把新表加入旧归档清理白名单。
生产迁移、重算和服务部署均需另有明确操作授权。

具体数据结构与验收见 [领域详设](../领域详设-StockVolumeAverage5d-2026-11-04.md)。

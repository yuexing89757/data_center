# ADR-0020：扣非净利润点时事实与增量同步

- 状态：Accepted
- 日期：2026-08-02
- 关联 Issue：#33
- 决策者：项目所有者
- 影响：财务盈利事实、Tushare Provider、调度、只读契约

## 决策

1. 新增 provider-neutral `DeductedProfit` 领域，保存证券、报告期、公告日期、实际公告日期、
   累计扣非净利润、单季度扣非净利润、更新标识、确定性修订键和 source code。金额使用
   Decimal，单位为 CNY；缺失与零严格区分。
2. Core 保存修订历史，不按 symbol/report period 覆盖。修订键由标准字段确定性计算，重放
   同一版本幂等；`first_observed_at` 记录数据中心首次观察时间。
3. as-of 查询同时要求有效公告日期不晚于查询日，且 `first_observed_at` 不晚于查询日末，
   防止后来发现的修订穿越回历史。
4. 当前 2000 积分 Token 已验证可访问 `fina_indicator` 与 `disclosure_date`，不可访问
   `fina_indicator_vip`。增量任务不依赖 VIP，也不每日逐股扫描全历史。
5. 每日扫描当前仍可能披露/修订的有限报告期 `disclosure_date`，筛选 actual date 或
   modify date 当日变化的股票/报告期，再逐项调用 `fina_indicator`。Provider 权限不足时
   以来源错误失败并保留 Operations 记录，不回退到其他来源。
6. 公告与披露计划可能在非交易日变化，任务每天 20:00 Asia/Shanghai 运行，不依赖交易
   日历。首次全市场历史回填必须另行确认权限、配额、范围和速率，本 ADR 不授权执行。
7. Raw 保留两类来源响应；Core 写入前校验证券、日期顺序、金额、自然键唯一性和修订键。
8. `api_v1` 提供有界 as-of RPC，返回最新已知修订以及累计/单季度扣非是否大于零；不暴露
   ingestion 或 Provider 字段细节，不引入 FastAPI。
9. 新任务加入受控 JobDefinition/WorkflowDefinition、WorkflowRun/JobExecution、陈旧恢复
   和本地只读任务页面。

## 限制

- `disclosure_date` 是增量发现线索，不是盈利事实来源；金额只来自 `fina_indicator`。
- 2000 积分路径按受影响股票逐项调用，披露高峰需限速；VIP 权限可用前不得切换全市场接口。
- Tushare 后续修订但披露日期接口未产生可发现变化时，可能延迟到周期性受控校验任务发现；
  首版不执行无界校验。

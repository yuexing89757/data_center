# ADR-0075：选股宝三池只读接口

- 状态：Accepted（项目所有者于 2026-10-29 要求将观潮使用的相关接口维护到数据中心）
- Issue：[#102](https://github.com/yuexing89757/data_center/issues/102)
- 范围：沿用 ADR-0067 的请求时有界读取模式，新增来源适配，不新增持久化领域。

## 决策

新增 `/api/v1/realtime/xuangubao/stock-pools`，只读选股宝固定 `pool/detail`，
允许涨停、炸板、昨日涨停三种池。支持最新及指定日期，当天按来源要求省略 date。
每次一次来源请求，禁止自动回退日期、重试、重定向和系统代理；8 秒超时、2,000,000字节正文、
最多 2000 条。沿用 API Key、统一错误和 ApiTimestamp；不入库、不保存 Raw、不触发 Worker。
SQL migration、PostgREST 和 Agent 数据库契约不适用。

Provider 返回标准证券代码、Decimal 百分比、来源连续板数和前一交易日连续板数；
不从“几天几板”猜测高度，不计算梯队、不判定断板。缺失保持 null，来源 -1 板数哨兵为 null。
昨日涨停池包含今天晋级和炸板的股票，消费者需要依次排除当日涨停、炸板后才得到剩余名单。

来源响应没有独立行情日期。响应区分 requested_date、source_event_date、observed_at：
source_event_date 仅来自本日涨停/开板事件，不来自 yesterday 事件；存在冲突日期则 502。
指定日期与本日事件不符则 502；无可核验事件时返回 null 和 unverified，不宣称请求日期已被来源确认。
该日期校验只能核对有事件的记录，不能独立证明昨日池所有未触板股票的行情时间。
接口不承诺全市场或任意历史日期完整性。

## 验证与发布边界

实现前已直接读取三池的最新/2026-10-28 样本，确认数值板数、涨幅、时间戳与来源参数。
合成 fixture 覆盖正常值、缺失、错误及边界，不提交真实市场 Raw。
本任务不部署生产，不更改观潮请求链路。正确仓库为 D:\java\git\gitPython\data_center。
保留已上线 `/xuangubao/limit-up`，复用其固定来源网络总截止时间、字段验证和配置。
同名旧目录 D:\java\git\gitOwn\data_center 的误放改动单独清理；不覆盖任何原有用户修改。

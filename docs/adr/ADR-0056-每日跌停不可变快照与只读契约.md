# ADR-0056：每日跌停不可变快照与只读契约

- 状态：Accepted
- 日期：2026-09-20
- 跟踪：GitHub Issue #81

## 背景

ADR-0021 已有沪深主板客观跌停事实及次一交易日生效的通用股票池，但
`/api/v1/daily-limit-up-list` 所依赖的同日涨停快照没有跌停对称契约。
现有 21:10 收盘五档任务只采集涨停池，不能为跌停股提供真实卖盘快照。

## 决策

1. 新建独立 `today_limit_down` 领域，不改写 `today_limit_up` 或通用股票池。首版
   仅覆盖 ADR-0021 已治理的沪深主板、精确交易日、未复权收盘价等于版本化跌停价。
   来源跌停榜只提供富化，不决定成员资格。
2. AKShare/EastMoney `stock_zt_pool_dtgc_em` 作为当日来源，保存不可变 Raw、
   ingestion 及 `source_observation`。来源报告封单资金与收盘盘口计算额分列。
   来源没有首次封板时间；`first_limit_down_at` 和累计封板时长保持 NULL，
   `duration_semantics='unavailable_without_event_stream'`，不得推算。
3. 21:10 收盘五档任务一次采集同日 ready 涨停池、跌停池的去重并集；
   原有涨停 bid-1 封单额只对涨停池计算。跌停快照冻结收盘卖一至卖五，
   仅当卖一价量完整、卖一价精确等于跌停价时计算卖一封单额。
4. 交易日 22:10 在 Worker 受控目录增加独立默认停用的快照任务。
   精确同日依赖缺失产生 deferred；部分输入或个别来源缺失产生 partial；
   来源整体失败产生零成员 failed 快照及失败 ingestion。任何状态均不得
   回退旧日期或伪装 ready。输入修订生成新版本，相同输入哈希幂等复用。
5. 新增 `GET /api/v1/daily-limit-down-list`。要求 `trade_date`，可选正整数
   `version`；`offset` 为 0..50000、`limit` 为 1..500，默认 200，按 symbol
   升序。只查询精确日期的指定或最高版本。响应含状态、版本、质量和血缘，
   方向字段使用 `limit_down`/`closing_ask`，金额和价格用十进制字符串，
   时间使用 Asia/Shanghai `YYYY-MM-DD HH:mm:ss`。
6. FastAPI 只调用有界、只读 `api_v1` RPC；API 角色没有内部表权限。
   所有 DDL 通过有序迁移，Worker 的内部表权限受 RLS 和最小授权控制。

## 限制与发布

- 来源只保证近期日期，首次上线不自动历史回填。
- 22:10 的来源可用性没有服务等级保证；失败必须留下可见缺口。
- 接受本 ADR 不授权生产迁移、任务启用、部署或数据回填；这些操作需单独确认。

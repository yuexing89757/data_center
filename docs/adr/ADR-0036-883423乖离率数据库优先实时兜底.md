# ADR-0036：883423 乖离率数据库优先实时兜底

- 状态：Superseded（FastAPI 实时兜底与异步写入由 ADR-0043 替代；计算公式不变）
- 日期：2026-08-15
- 关联 Issue：#50
- 决策者：项目所有者
- 替代范围：替代 ADR-0035 的数据库唯一读取决定，保留其 MA5/BIAS5 公式
- 扩展：ADR-0003、ADR-0011、ADR-0033

## 背景

ADR-0035 发布的只读接口依赖 `core.board_index_daily_bar`，但生产库可能尚无
`THS:883423` 日 K、历史不足 34 条，或最新记录已经落后。项目所有者要求接口
优先使用数据库；数据库无、数据不足或陈旧时访问固定同花顺年度行情地址，立即
返回结果，并异步把可追溯来源事实写入数据库。

## 决策

1. `GET /api/v1/board-indexes/883423/bias` 不增加输入。先调用有界数据库 RPC；
   无记录、少于 34 条或最新日期早于交易日历最近应有交易日时使用 `P0002`
   请求实时兜底。其他数据库错误不得触发 Provider。
2. 实时地址固定为
   `https://d.10jqka.com.cn/v4/line/bk_883423/01/{year}.js`。代码、URL和年份
   均不接受客户端输入；超时固定 5 秒。当年不足 34 条时补读上一年度。
3. THS 字段和 JavaScript 包装只在 `akshare_ths` Adapter 内解析。API 计算只
   使用标准 `BoardIndexDailyBarRecord` 和 `Decimal`。MA5、BIAS5、前日方向、
   30 日极值及并列规则继续遵守 ADR-0035。
4. 实时响应在返回前必须完成不可变 Raw 捕获，随后进入容量为一的单写线程
   队列。响应标记 `data_origin=ths_live`、`persistence_status=queued`；数据库
   命中标记 `database`、`persisted`。两种响应都包含 `fetched_at`。
5. API 角色不获得内部表 DML。新增严格受限的 security-definer RPC，只接受
   固定板块、Provider、Schema 版本、有界 Raw 元数据和标准行；在一个事务中
   建立 IngestionRun、RawManifest，并按自然键幂等写入
   `core.board_index_daily_bar`。
6. 持久化 RPC 必须验证哈希、字节数、行数、日期唯一性、交易日历、已知板块、
   正价格、OHLC 范围及非负成交量/额。不得把 partial、多来源或无 Raw 数据
   登记为成功批次。
7. THS 失败映射 502，Raw/持久化子系统不可用映射 503，队列繁忙映射 429。
   异步失败记录安全日志并保留 Raw；不得静默声明已经入库。
8. 本能力是 ADR-0011 的第二个显式实时例外。它不增加 Worker 或 OS 定时任务，
   不允许任意 Provider 代理，也不改变已有 BoardIndex 手工采集能力。

## 后果

- 已有新鲜数据时请求只访问 PostgreSQL；首次、历史不足及陈旧状态可自动恢复；
- HTTP 响应与异步数据库登记解耦，但 Raw-before-return 保证来源证据不会丢失；
- API 获得一个新增但严格有界的写能力，需要迁移、权限测试和队列生命周期治理；
- 同花顺不可用时明确失败，不用旧库数据伪装为最新结果。

## 验收

- 数据库命中不访问同花顺；三种 `P0002` 情况触发固定端点；其他数据库错误
  不回退；
- 年初能够补读上一年度并产生至少 34 条输入；
- 实时响应、Raw、lineage 和 Core 日 K 可由哈希及自然键关联；
- 重复实时响应幂等，队列边界和错误映射有测试；
- 不运行全量 PostgreSQL 回归，只运行快速门禁与本功能聚焦数据库冒烟。

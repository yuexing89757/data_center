# ADR-0041：2026-08-18 竞价快照五档一次性受控修复

- 状态：Accepted
- 日期：2026-08-18
- 关联 Issue：#55
- 决策者：项目所有者
- 澄清：ADR-0028 的通用 Raw replay 禁令保持有效

## 背景

`2026-08-18` 的 `call_auction_market_snapshot` 成功批次
`76e4416d-024f-45f6-8a30-cf58d7e3ad4e` 在五档字段 migration 和新版 Worker
部署前完成。该批次的不可变 PYTDX Raw 已包含买卖五档，但数据库新增字段及
`seal_amount` 均为 `NULL`，导致只读接口不能返回已有来源证据能够确定的封单额。

## 决策

1. 允许执行一次受控的原批次字段修复，只处理上述固定 ingestion；不创建新的
   IngestionRun，不修改 Raw、Manifest、既有批次状态或其他来源事实字段。
2. 修复入口必须默认只读；只有显式 `--apply` 才允许写入。
3. 写入前必须校验 Manifest 的安全相对路径、JSONL 格式、schema version、字节数、
   SHA-256 和 5208 行，并证明 Raw 的标准 symbol 集合与目标批次数据库 symbol 集合完全一致。
4. 目标批次在写入前必须仍处于 succeeded 状态，且全部五档和封单额字段均为空。
   任一条件不满足时整个操作失败且零写入。
5. 价格为零标准化为缺失；数量单位从 PYTDX 手转换为股。价格为零但数量大于零时
   保留数量。卖一量为空或零且买一价量完整时，`seal_amount = bid1_price * bid1_volume`。
6. 更新在单个数据库事务内完成，并在提交前重新验证 5208 行均与 Raw 标准化结果一致。

## 边界

- 本决策不启用 `RawReplayService` 的该数据集路径，不形成可复用的 operational replay。
- 不允许用今日证券全集、一般 known-symbol 集合或单纯行数代替精确集合比较。
- 脚本固定批次和预期值，完成本次修复后不作为未来批次的通用工具。
- ADR-0028 的其他决策继续有效。

## 验收

- dry-run 输出 5208 个匹配 symbol、零集合差异和待更新状态，不写数据库；
- apply 后 5208 行五档与 Raw 一致；
- `SSE:603089` 的买一价为 11.8、买一股数为 7065600、卖一股数为空、
  封单额为 83374080；
- `/api/v1/call-auction-one-price-limits` 对具备封单证据的记录返回非空封单额。

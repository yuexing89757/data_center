# ADR-0014：股票每日指标快照

- 状态：Accepted
- 日期：2026-08-02
- 关联 Issue：#29
- 决策者：项目所有者
- 影响：新增 StockDailyIndicator 领域；扩展 ADR-0013 的 Tushare 能力

## 背景

Tushare `daily_basic` 提供按股票、交易日形成的收盘价、换手率、估值倍数、股本、
市值和收盘涨跌停状态。它包含严格意义的自由流通股本 `free_share`，但数据语义既不
属于 OHLCV Daily Bar，也不是只有股本发生变更时才产生的 Capital 事件。

## 决策

1. 新增 `StockDailyIndicatorSnapshotRecord`，自然键为 `(symbol, trade_date)`。
2. 来源百分比保留“百分点”口径，领域字段显式使用 `_pct`；估值倍数和量比保持
   无量纲 `Decimal`。
3. 来源股本单位“万股”在 Adapter 内乘以 10,000 转换为“股”，转换后必须为整数；
   来源市值单位“万元”乘以 10,000 转换为“元”。任何数值不得经过 `float`。
4. `free_float_shares <= circulating_shares <= total_shares`；流通市值不得大于总市值。
   缺失值保持 `None`，不得用零填充。
5. Tushare `limit_status` 映射为来源无关枚举：flat、rise、limit_up、
   one_price_limit_up、fall、limit_down、one_price_limit_down、unknown。
6. 该记录是来源计算/发布的每日快照，不得写入 `ShareCapitalRecord`，也不得宣称为
   项目按版本化算法自主计算的 DerivedMetric。
7. 首期 Provider 仅为 `tushare`，Raw schema 为 `tushare.stock_daily_indicator.v1`；
   不加入默认自动路由。
8. Core 使用 append-by-natural-key UPSERT 保存来源修订并保留最新 ingestion lineage；
   只读查询不暴露 ingestion_id/source_code。
9. 查询按 ADR-0010 通过现有 PostgREST `api_v1` 边界提供，不引入 FastAPI/MCP 服务。

## 后果

- 可以稳定区分普通流通股本和自由流通股本，并支持每日估值/换手率研究。
- 与 K 线相同日期的 close 可用于后续质量核对，但首期不因微小来源差异阻断写入。
- Tushare 权限、总量和口径变更仍属于外部依赖，必须保留 Raw 以支持重放。

## 验收

- 领域、Adapter、Raw replay、Pipeline、Persistence、migration 和查询契约测试通过；
- 单位、Decimal、缺失值、层级关系、重复键和引用完整性均有测试；
- Ruff、mypy、pytest 与 migration 检查通过。

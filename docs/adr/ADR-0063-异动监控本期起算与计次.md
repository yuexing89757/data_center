# ADR-0063：异动监控本期起算与计次

- 状态：Accepted（2026-09-30，项目所有者明确选择“从9月1日重新计次，明确显示本期内次数”）
- Issue：#87，关联 #69、#85
- 补充 ADR-0060、ADR-0061；正式公告与旧算法批次不变。

## 决策

当前独立监控采用 `regulation-monitor.v3`，本期起算日期为 `2026-09-01`。
首个交易日以空测算事件历史开始；其后仍要求前一交易日的同版本、同起点连续检查点。
这是明确限定统计范围的系统测算，不代表自规则生效以来的完整异动次数或交易所认定。
普通及严重价格偏离窗口不早于本期起点，严重次数条件只计本期事件。
换手比较使用所需的真实前期事实，但换手事件次数也仅计本期。

`RegulationCalculationInput.monitor_start_date` 表达计算输入范围，保存于现有不可变
`monitor_context.source` JSON，纳入 v3 输入哈希。旧版 v1/v2 默认起点为2026-07-06，
新增字段不改变其既有输入哈希或投影语义。链校验比较版本和起点，防止混用检查点。

有界 RPC 与 FastAPI 返回 `monitor_start_date`、`count_scope_label`。
标签为“本期内次数(最近10个交易日)”；已有10日计数字段仍保留滚动窗口含义。
本期不是每月自动重置；后续交易日继续接续该起点，变更起点需要新的明确决策。

缺来源事实保持资料不足，不从旧版事件或正式公告推填本期测算次数。
生产依旧使用受保护迁移、专用 Worker 身份与现有22:30工作流；不新增OS任务。

API元数据、RLS及幂等。生产只补算2026-09-01至最近已收盘交易日，先预检再逐日发布。

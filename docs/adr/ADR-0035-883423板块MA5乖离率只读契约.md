# ADR-0035：883423 板块 MA5 乖离率只读契约

- 状态：Accepted
- 日期：2026-08-15
- 关联 Issue：#49
- 决策者：项目所有者
- 扩展：ADR-0003、ADR-0010、ADR-0011

## 背景

外部消费者需要读取同花顺动态板块 `THS:883423` 最新已入库交易数据，
并获得当前收盘价相对五日简单移动平均线的乖离率、相对上一可用交易日的
变化方向，以及最近 30 个板块交易日内的乖离率极值。

这些值属于新的客观派生价格语义。FastAPI 不能直接查询 `core`，也不能在
请求过程中触发同花顺采集或写入派生结果。

## 决策

1. 新增 `GET /api/v1/board-indexes/883423/bias`，不接收交易日或代码参数，
   始终使用 `core.board_index_daily_bar` 中 `THS:883423` 的最新可用记录。
2. 新增有界 RPC `api_v1.query_board_index_bias_latest()`。FastAPI 只调用该
   RPC，不直接读取内部 Schema。RPC 只授予 `market_data_api`，语句超时为
   5 秒。
3. `MA5` 是包含当日在内最近五个可用板块交易日正收盘价的算术平均值；
   `BIAS5=(close-MA5)/MA5*100`。价格、均线与百分比使用 `numeric`/`Decimal`，
   不经过二进制浮点数。
4. 当前 BIAS5 与上一可用板块交易日 BIAS5 比较，返回 `up`、`down` 或
   `flat`。任一值无效时方向为 null。
5. 极值窗口为包含最新日在内的最近 30 个已存储板块交易日。历史不足 30
   日时使用已有有效 BIAS5，并返回实际 `bias_sample_count`；不足五条正收盘
   记录时相关字段为 null。并列极值取最近交易日。
6. RPC 最多读取最近 34 条板块日 K。不存在任何日 K 时使用 `P0002`，由
   FastAPI 映射为 404。不得回退日期、填充缺口、访问 Provider 或在线抓取。
7. 首版在查询时计算，不新增派生表、CalculationRun 或 Worker 定时任务。
   算法版本固定为 `board_index_bias_v1`；未来改变窗口、公式或缺失值规则时
   必须新增 ADR 和算法版本。
8. 同步 PostgREST、Agent 工具和 FastAPI 三份已检入契约，并更新 BoardIndex
   及 FastAPI 文档。

## 后果

- 返回值始终反映最新已持久化的来源事实，不会产生单独派生批次的陈旧状态；
- 单次请求只处理固定板块和最多 34 条记录，成本有数据库硬边界；
- 该接口不是交易信号，不表达主观强弱，仅返回确定性价格统计；
- 若未来需要跨大量板块批量计算或历史版本重放，应另行评估持久化派生模型。

## 验收标准

- 无输入即可获得 `THS:883423` 最新可用交易日结果；
- 五日均线、乖离率、前日方向和 30 日极值符合本 ADR 的精确定义；
- 不足历史、并列极值、空数据、Decimal 输出和权限边界均有测试；
- migration、三份公共契约和相关文档保持同步。

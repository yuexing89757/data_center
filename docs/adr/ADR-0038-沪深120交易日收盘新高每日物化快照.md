# ADR-0038：沪深 120 交易日收盘新高每日物化快照

- 状态：Accepted
- 日期：2026-08-16
- 关联 Issue：#51
- 替代范围：ADR-0037 的请求时实时聚合决定

## 背景

`core.daily_bar` 已超过一千万行。ADR-0037 首版 RPC 在每次 API 请求时确定最新日期并聚合
120 个交易日，生产验证触发 10 秒语句超时。该结果只随日 K 输入修订而变化，属于可版本化、
可重算的客观派生快照，不应在公共请求路径重复计算。

## 决策

1. 新增 `derived.close_price_new_high_120d_snapshot` 与
   `derived.close_price_new_high_120d_member`。主表记录交易日、版本、ready 状态、候选/有效/
   遗漏/成员计数、分组遗漏计数、输入和内容哈希、算法版本、calculation lineage 与生成时间；
   成员表记录 symbol、当日历史名称、当日收盘、此前 119 日最高收盘和突破百分比。
2. 计算口径继续遵守 ADR-0037：只含 SSE/SZSE 普通股票，要求连续 120 个市场交易日都有正收盘
   且状态为 `trading` 或 `unknown`；当日收盘必须严格大于此前 119 日最高收盘，相等不算。
3. Persistence 用 `(market, trade_date)` 日期范围索引读取 120 日窗口并产生每证券有界聚合输入；
   纯 Calculator 负责资格判断、Decimal 突破率、排序和确定性哈希，不在 Calculator 中访问数据库。
4. 同一 trade date 与 input hash 幂等复用。输入内容变化时创建新的 calculation 和递增版本，
   历史 ready 快照不可修改。成功但零成员仍写主快照，避免 API 回退到更早的非空交易日。
5. Worker 任务 `close-price-new-highs-120d-daily` 固定在周一至周五 21:30
   （Asia/Shanghai）触发，代码目录默认启用。环境变量只允许启用或停用，不允许配置执行时间。
   非交易日成功跳过；缺少同日终态 `daily_market` workflow、120 个日历会话或可用候选输入时失败，
   只记录 Operations 终态，不发布、不覆盖 ready 快照。
6. `GET /api/v1/close-price-new-highs-120d` 保持无参数、不分页和既有响应语义，但 RPC 改为只读取
   最近 trade date、最高 version 的 ready 快照。请求路径不得读取 `core.daily_bar`、触发计算或访问网络。
7. API 角色只获得有界 RPC execute 权限，没有 derived 底表权限。Worker 通过 RLS 仅获得所需
   select/insert 权限。所有 Schema 变化只通过顺序 migration 应用。
8. 部署迁移和 Worker 后手工执行一次同一受控 workflow，为最新可用交易日创建首个 ready 快照；
   此后仅由 Worker APScheduler 触发，不新增 cron、Windows Task Scheduler 或其他系统级计划。

## 后果

- API 读取成本与 120 日历史规模解耦，并能在 10 秒硬限制内稳定返回。
- 日 K 修订不会静默覆盖旧结果，会产生可追溯的新版本。
- 21:30 只是尝试时间；依赖未完成时任务显式失败，下一次调度或受控手工命令重试。
- ADR-0037 的市场范围、价格口径、完整历史与排序语义继续有效，仅废止请求时实时聚合。

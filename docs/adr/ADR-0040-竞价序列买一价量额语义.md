# ADR-0040：竞价序列买一价量额语义

- 状态：Accepted
- 日期：2026-08-17
- 关联 Issue：#53
- 扩展：ADR-0034

## 背景

生产 Raw 证明 pytdx 在开盘集合竞价结束前把普通成交字段 `price/open/high/low` 报为零，
同时在买一档提供项目所有者需要的竞价价和量。原实现按普通行情语义将零价格规范化为 NULL，
又只把普通成交字段写入全市场竞价序列表，导致 09:25 前的标准快照没有可用价格。

## 决策

1. 以 Round 的计划时间判断边界：`scheduled_at < 09:25:00` 时使用竞价语义，
   `scheduled_at >= 09:25:00` 时使用开盘成交语义。判断时区固定为 `Asia/Shanghai`，
   不使用 Worker 收齐时间或来源的非权威时钟。
2. 竞价语义按项目所有者指定复用现有字段：`last_price = bid1.price`、
   `cumulative_volume = bid1.volume`、
   `cumulative_amount = bid1.price * bid1.volume`。Provider 已把买一量从手转换为股，
   金额使用 Decimal 计算且单位为 CNY。
3. 买一价或买一量任一缺失时，上述三个字段全部为 NULL；不得使用卖一、昨收、零值或
   相邻档位回退。`high_price` 和 `low_price` 继续保留普通行情来源规范化结果，不制造竞价高低价。
4. 09:25:00 起继续使用 pytdx 的真实 `price`、累计成交量和累计成交额。
5. 新增非空 `value_semantics`：`auction_indicative`、`opening_trade`、
   `legacy_source_quote`。调用方必须依据该字段解释复用的价量额字段。
6. ordered migration 只为已有行标记 `legacy_source_quote`，不修改历史价量额，也不从 Raw
   回填。Raw JSONL、Manifest、IngestionRun、冻结全集、32 轮、20 秒节奏、每批 80 只、
   endpoint 和 09:26 任务均不改变。
7. bounded RPC 与 FastAPI item 返回 `value_semantics`；不新增 PostgREST 或 Agent 工具表面。

## 后果

新采集的 09:25 前记录将按买一价、买一股数和两者乘积提供用户需要的价量额，但它们不是
真实成交事实。显式语义字段消除这一兼容性复用造成的歧义。历史记录仍可追溯原 Raw，且不会被
本决定静默重写。

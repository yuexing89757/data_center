# ADR-0070：定时历史结果归档清理

- 状态：Accepted（项目所有者于2026-10-23明确要求“任务加入 建议表”）
- 关联：Issue #84、ADR-0058、ADR-0069

将已说明的竞价附属明细/已结束会话、技术因子、资金流、龙虎榜、监管结果和旧版本快照
加入现有03:00 Worker任务。新范围按上海执行日减一个自然月、严格小于截止日筛选。
既有竞价序列在线3个已完成交易日、历史6个月、质量白名单30天、Raw压缩7天保持不变。
本决定只扩展历史结果归档清理，不扩展Raw退役、质量规则白名单、基础资料或计算输入删除。
日K回看、股东比较期、股票池基础日数据、采集/计算/单位认证血缘均不纳入新日期删除。

父子事实组成一个事务单元：先锁定父行，锁定并完整归档子行，按子到父顺序删除；
任何外部引用、大小限制、归档校验失败或预算耗尽均回滚该单元。不得拆掉保留父项的成员。
股票池质量按计算ID共享，仍有快照使用时保留。竞价序列会话必须没有在线/历史序列引用。
监管持续监测链及输入保留；被监测链引用的计算结果保留。

完整PostgreSQL JSON文本以无损gzip归档至受控Worker目录，保留原始数值/null、表结构、
主键、截止日及workflow身份；发布后重新校验。归档登记与精确删除在同一数据库事务提交。
只通过有序迁移授予固定表目录的有界内部锁定/删除函数执行权限，不给Worker新增任意UPDATE。
公共API无新写入口；不改变任何计算语义和数量认证。恢复先验证归档、实例/结构，冲突拒绝。

新步骤预算最多10分钟、每次100000行、单单元最多10000行/32MiB，纳入原有30分钟总预算。
表间轮转，每轮每组一个事务，避免大表长期挤占其他范围；失败组记录原因并让其他组继续。
默认预览只读且有界，不做全表计数；报告区分完整、未完成、失败及保护范围。
归档目录须纳入现有备份；生产上线须核对磁盘、权限、迁移、预览和实际执行，不以本地测试
声称线上已启用。数据库逻辑删除仅释放可复用页，不保证OS立即释放空间。

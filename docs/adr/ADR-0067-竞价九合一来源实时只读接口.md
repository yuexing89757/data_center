# ADR-0067：竞价九合一来源实时只读接口

- 状态：Accepted（项目所有者于2026-10-13确认12类来源接入范围）
- Issue：[#89](https://github.com/yuexing89757/data_center/issues/89)
- 日期：2026-10-13
- 范围：现有FastAPI实时读取模式增量，不建设持久化分钟行情领域。

## 决策

1. 按来源分组公开12个GET路由，统一归类“实时接口”：东方财富8个、腾讯3个、新浪1个。
   上游主题服务使用POST，但公共接口仍为只读GET；完整请求体由固定Provider构建。
2. 沿用ADR-0045/0059的请求时直连例外：API Key鉴权、不入库、不保存Raw、不触发Worker，
   不修改PostgREST/Agent契约。一次公共请求只读一次上游，不自动翻页、重试或跨源兜底。
3. 对宪法及AGENTS的分钟行情禁令作窄例外：只允许读取腾讯当日分钟级累计序列，
   不采集tick/逐笔、不新增调度和持久化分钟领域、不计算均价或交易策略。
   前复权日/周K只作为第三方临时读结果，不写Core，不改变普通DailyBar来源和复权算法。
4. URL固定白名单，腾讯K线仅允许web/ifzq两种服务器选择；不接受用户URL、UT、来源字段表达式、
   任意来源请求体。禁止重定向和系统代理；配置1～10秒超时、8MB正文上限。
5. Provider边界标准化命名、证券代码及单位，数值用Decimal、零与缺失分开。
   东财及腾讯行情/K线的手转股；新浪量以股读取。分时量额为来源累计值，不重复累加。
   主题列表bf3为板块涨幅，f3为领涨股涨幅；今日主题f3为板块涨幅。
6. 只公开有明确消费及解释的字段；不公开不明f615/f630/f104、数组尾部或随机评分。
   新浪复权未明确，标注unspecified；腾讯回退未复权day/week时回显none，不能伪称前复权。
7. 所有查询有页长/周期/代码/日期约束，日期不得未来。来源显式失败、结构异常、超限、
   日期不符返回统一502，参数错误422，真实空数组200；无模拟数据回退。
8. 响应注明来源网站、固定上游地址、请求参数/请求体、用途、上海观测时间和persisted=false。
   来源数据日期与观测日期分开；列表支持单页和显式下一页，不保证全市场完整性。

## 文档与验证

详见[接口说明及实现边界](../竞价九合一来源实时接口.md)。更新OpenAPI、README、Provider和路由测试。
没有存储变更，SQL migration不适用；不运行生产迁移、采集、历史回补或部署。
2026-10-13作少量只读来源抽查，实测分时累计口径、主题字段差异及涨停池日期不符情形；
抽查不是服务可用性保证，不将临时线上市场响应提交为Raw或测试fixture。

## 2026-10-28：选股宝最新涨停池来源增补

项目所有者明确要求将选股宝最新涨停池接入现有FastAPI实时接口，并委托实现细节；
任务为[#101](https://github.com/yuexing89757/data_center/issues/101)。沿用上述请求时直连模式，
仅新增`GET /api/v1/realtime/xuangubao/limit-up`，固定匿名来源
`https://flash-api.xuangubao.cn/api/pool/detail?pool_name=limit_up`。一次公共请求只读一次来源，
使用原API Key鉴权，不重试、不跨源兜底、不保存Raw、不入库、不触发Worker。
不新增历史查询、独立题材查询、同花顺补充、成交额估算或数据中心涨停池计算。

本次字段范围包含池内来源原因、关联板块和已观察的统计字段。对第6条作限于本路由的说明：
语义明确的价格、比例、时间、计数由适配器规范化；未核实统计只可放在具名的
`source_statistics`对象中逐项声明不确定口径，不得进入标准数量、金额或派生契约。
尤其`total_capital`和`non_restricted_capital`不认证为股数或人民币市值，
不绕过ADR-0068的`stock-quantity.v1`读写及计算门禁。来源观点标明出处，不作为中心判断。
来源未来或混合事件日期、重复证券/JSON键、非法数值、结构异常均整批失败。
仅在每条记录都有当前涨停事件且日期一致时给出`source_date`；空池或缺证为空，
不以观测日填充，允许闭市后最新池仍为上一来源日。

连接沿用既有受限DNS和单地址方式，禁止系统代理和重定向；总网络截止时间1～10秒
（默认8秒）、正文上限2,000,000字节、最多5,000条。具体字段和验收见
[选股宝接口说明](../选股宝涨停池来源实时接口.md)。仅修改FastAPI契约；
没有新增持久化领域或数据库结构，SQL迁移不适用。2026-10-28已部署API版本`9fe6462`，
详见[发布验收](../runbooks/xuangubao-limit-up-release-2026-10-28.md)。

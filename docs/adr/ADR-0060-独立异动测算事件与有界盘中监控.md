# ADR-0060：独立异动测算事件与有界盘中监控

- 状态：Accepted（项目所有者于2026-09-29确认设计及实施计划，并要求连续实施）
- 日期：2026-09-29
- 关联 Issue：#69
- 补充 ADR-0048；其官方事件路径、旧算法和公开字段语义保持不变。

## 决策

新增独立 `regulation-monitor.v1` 路径，沿用26条版本化规则和既有适用范围。
`regulation.calculated_event` 仅保存完整收盘输入产生的确定性测算事件，不写正式 `regulation.event`。
按交易日顺序计算，同一股票/日/级别/方向/类型去重，命中规则与实际窗口聚合。
普通价格事件下一交易日起重置普通价格窗口，两个方向共用重置点；严重事件在当日普通事件加入后判断，
其下一交易日重置严重及普通价格窗口。换手独立，不参与价格次数。它们均为系统模拟，不是交易所认定。

最近10交易日历史涨/跌次数与严重规则本轮有效同向次数分开；后者排除严重模拟重置前事件。
连续状态从2026-07-06或可信连续检查点建立。缺口不得重启为零；更正须生成新版本并顺序重算后继链。
领域对象无批次ID；输入/状态/事件与正式公告输入清单由持久化绑定同一发布批次。
官方次数无覆盖证明返回null，旧接口计数原义不改。

允许公开 FastAPI 在有界 api_v1 输入 RPC 基础上读取外部即时行情并进行纯计算；禁止公开写库、触发补采或Worker。
候选查询限1–100，实时查询限1–50；固定批次/日期，8秒预算、最多2个上游并发。
基准仅 SSE:000002、SZSE:399107、SZSE:399102，不能按股票代码路由。活跃会话时股票与指数各自年龄及差值不超过60秒。
盘中达标不持久化、不增加历史计数；下一交易日是按当前价假设收盘后、指数-2%/0%/+2%的条件路径，包含临时重置。
今日以有效前收、次日以假设收盘参考价反解，Decimal到分方向取整并回代；缺参考价/公司行动输入时不给假精确值。
换手率使用无限售股口径，缺失保持缺失，不反解价格。

新增候选和批量监控接口，不改变旧监管或开盘啦契约；时间格式遵循现有 ApiTimestamp。
Worker复用既有监管工作流，补充收盘测算步骤，不增加30秒全市场任务。
补算默认只读预检；生产迁移、补采、重算和启用新增任务步骤分别授权。当前接受不代表生产已执行。

## 验收与边界

连续计数/重置/去重、版本发布、只读角色、有界RPC、日历与指数、动态反解、错误与null语义均需测试。
须完成隔离数据库验证；线上库不能作为测试库。页面必须明确测算来源、观察名单范围、缺失原因及时间。
不新增主观评级、交易策略、分钟持久化或推送。不覆盖旧批次，回退仅切换消费者版本。

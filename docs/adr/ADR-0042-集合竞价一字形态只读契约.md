# ADR-0042：集合竞价一字形态只读契约

- 状态：Accepted
- 日期：2026-08-18
- 关联 Issue：#56
- 决策者：项目所有者
- 扩展：ADR-0011、ADR-0034、ADR-0040

## 背景

`realtime.call_auction_market_series_snapshot` 已保存沪深上市股票在开盘集合竞价期间
每20秒一次的来源事实，但消费者需要一个稳定列表，识别指定观察窗口内竞价价格始终相同、
且相对昨收涨跌幅处于中性区间的股票。该形态是由既有来源事实确定性计算的客观结果，属于
Market Data Center 边界。

## 决策

1. 新增 authenticated FastAPI 只读接口
   `GET /api/v1/call-auction-one-price-patterns`，参数 `trade_date` 可选。
2. 固定观察窗口为 `09:15:20–09:24:40 Asia/Shanghai`，对应
   `sample_seq=1–29` 共29轮。`09:15:00`、`09:25:00` 和 `09:25:20`
   不参与会话完整性、价格一致性或结果计算。
3. 一个会话只有在上述29个 Round 全部为 `succeeded`、成功数等于预期数且均有
   `selected_ingestion_id` 时才符合查询条件。窗口外 Round 的状态不影响资格；因此整体
   session 可以是 `succeeded` 或 `partial`。同一交易日存在多个合格会话时选择最新启动者，
   再以 `session_id` 确定性打破并列。
4. 每只股票必须在选定会话中恰有29个不同采样点，`last_price` 与 `previous_close` 全部非空且
   大于零，`value_semantics` 全部为 `auction_indicative`；29个竞价价完全相同且29个昨收完全一致。
5. 精确涨跌幅为 `(one_price / previous_close - 1) * 100`。筛选使用未舍入精确值和闭区间
   `[-4, 4]`，响应值四舍五入至10位小数。
6. 范围使用会话启动时冻结的 SSE/SZSE listed-stock 全集；包含主板、创业板和科创板，
   不含 BSE、ETF、可转债和指数。历史查询不得用当前证券状态重新解释当日冻结集合。
7. 显式 `trade_date` 只查询该日，无合格会话返回404且不回退。不传日期时选择最近存在合格
   会话的交易日。合格会话存在但没有符合形态的股票时返回200和空列表。
8. 结果不分页，最大边界为该会话的 `universe_count`；按涨跌幅降序、六位代码升序、标准
   symbol 升序排列。
9. FastAPI 只能调用 `api_v1` 中 statement timeout 为10秒的有界只读 RPC。RPC 仅授权
   `market_data_api`，不授权 public、anon 或 authenticated PostgREST 角色。

## 公共响应

响应返回 `trade_date`、`session_id`、`session_status`、`window_start`、`window_end`、
`round_count=29`、`candidate_count` 和 `items`。每项返回 `symbol`、六位 `code`、
交易日有效 `name`、`exchange`、`one_price`、`previous_close`、`change_pct` 和
`sample_count=29`。Decimal 按现有 FastAPI 契约序列化为字符串。

## 后果

- 新增 ordered migration、私有 bounded RPC、支持索引、FastAPI 模型/查询/路由、中文 OpenAPI
  和聚焦测试；
- 只更新 `contracts/fastapi-openapi-v1.json`。该接口不新增直接 PostgREST 或 Agent Tool 表面；
- 不新增表、Worker job、环境配置、网络 Provider 调用、数据写入或缓存；
- 计算始终可由选定 session 的29轮来源事实重现。

## 验收

- 精确覆盖29轮、闭区间边界、缺轮、空价、变价、昨收变化、错误语义和范围排除测试；
- 测试证明窗口外三个 Round 失败不影响合格会话；
- 显式日期不回退，不传日期确定性选择最近合格会话；
- 401、404、503、中文 OpenAPI、Decimal 字符串和受限 RPC grant 均有契约测试；
- 聚焦测试、完整本地门禁和隔离 PostgreSQL integration tests 通过。

# ADR-0066：专业版股票技术因子日快照

- 状态：Accepted（项目所有者于 2026-10-10 确认）
- 日期：2026-10-10
- 关联 Issue：[#88](https://github.com/yuexing89757/data_center/issues/88)
- 影响：新增 StockTechnicalFactor 来源事实领域、Worker 任务及独立有界读契约

## 背景

用户要求保持现有每日指标不变，新增 Tushare `stk_factor_pro` 专业版技术因子，
每天定时更新。接入前仓库只有 daily_basic 每日指标，没有 stk_factor 技术因子实现。

## 决策

1. 新增独立来源事实日快照，自然键 `(symbol, trade_date)`；不改变原有指标。
2. 保存官方目录全部技术指标，明确区分不复权、前复权、后复权与共同计数项。
   领域使用标准指标名，Decimal 与 None；不新增复权价格事实或主观信号。
3. 请求、校验及写入以完整市场单日批次为边界；Raw 保留原响应以便审计和重放。
   来源失效、完整性不可确认或硬不变量失败时保留明确缺口，不回退其他来源。
4. 新增有序 SQL migration 建立独立 Core 快照表和最小权限；四组指标以标准键
   JSONB 数字保存，公开读返回十进制字符串/空值，快照整体 UPSERT，禁止跨批次拼接。
5. 仅通过有界 api_v1 RPC 公开读取，FastAPI 仅调用该 RPC；同步三份查询契约。
6. 新增 Worker 任务，默认上海时间工作日 21:00 核验日历并更新当日全市场快照。
   复用受控任务目录与 operations，不添加操作系统采集计划任务。
7. 首期保留历史快照、不自动清理、不默认全历史回补；支持显式单日重试及 Raw 重放。

## 具体设计和验收

见 [StockTechnicalFactor 领域详设](../领域详设-StockTechnicalFactor-2026-10-10.md)。
新领域、Provider、重放、Pipeline、存储、migration、契约与调度均须有测试；
完成完整本地检查，并明确报告无法执行的隔离数据库检查。

## 后果

保留来源已计算指标及其目录版本，不宣称本项目能从行情精确重算来源算法。
历史存储随交易日增长；Tushare 权限、覆盖和数据就绪时间仍为外部依赖。
项目所有者已确认本 ADR 及具体设计；该确认不授权生产迁移、采集或部署。
